# 04. Adapters and Boundaries

## 목표

강의 주제 중 `임피던스 불일치`, `어댑터`, `추상화와 산출물 구분`,
`재사용과 애플리케이션 전용 코드의 경계`를 다룹니다.

외부 시스템은 문자열, 정수 코드, C 스타일 함수처럼 내부 모델과 다른 형태를 쓰는
경우가 많습니다. 어댑터는 이런 차이를 한 곳에 가둬 내부 코드가 도메인 타입으로
일관되게 동작하게 합니다.

## C++ 기초 문법 포인트

- `enum class`: 서로 섞이면 안 되는 상태 값을 강한 타입으로 표현합니다.
- `std::optional`: 값이 있을 수도, 없을 수도 있음을 표현합니다.
- `switch`: 열거형 값에 따라 분기합니다.
- 네임스페이스: 외부 API와 내부 코드를 구분합니다.

## 설계 포인트

외부 코드가 바뀌어도 내부 도메인 모델 전체가 흔들리지 않도록 변환 지점을 작게
유지합니다. 이것이 시스템 경계 설계의 기본입니다.

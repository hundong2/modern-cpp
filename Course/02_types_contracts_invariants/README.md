# 02. Types, Contracts, Invariants

## 목표

강의 주제 중 `타입 시스템`, `대칭성`, `불변식`, `넓은 계약과 좁은 계약`을
기초 예제로 설명합니다.

불변식은 객체가 살아 있는 동안 항상 지켜야 하는 조건입니다. 예를 들어 금액은
음수가 아니어야 하고, 계좌 잔액도 음수가 되지 않아야 합니다.

## C++ 기초 문법 포인트

- 생성자: 객체가 만들어질 때 유효한 상태로 초기화합니다.
- `explicit`: 의도하지 않은 암시적 변환을 막습니다.
- 예외 `throw`: 계약 위반을 호출자에게 알립니다.
- `[[nodiscard]]`: 반환값을 무시하지 말라는 컴파일러 힌트입니다.
- `operator+`: 사용자 정의 타입에도 연산자 의미를 부여할 수 있습니다.

## 메모리 관점

`Money`는 `int` 하나를 감싼 작은 값 타입입니다. 대부분의 상황에서 스택에
저장되며 복사 비용이 작습니다. 이런 값 타입은 포인터보다 함수 경계에서 안전하고
명확합니다.

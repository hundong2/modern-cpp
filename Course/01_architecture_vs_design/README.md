# 01. Architecture vs Design

## 목표

아키텍처는 시스템 전체의 큰 책임 분리와 데이터 흐름을 정합니다. 설계는 그 큰
방향 안에서 클래스, 함수, API, 자료구조를 어떻게 둘지 결정합니다.

예제에서는 주문 처리 시스템을 아주 작게 모델링합니다.

- 아키텍처 관심사: 주문 입력, 결제, 영수증 출력이라는 큰 흐름
- 설계 관심사: `Order`, `PaymentGateway`, `ReceiptPrinter` 같은 타입과 함수 경계

## C++ 기초 문법 포인트

- `struct`: 데이터를 묶는 사용자 정의 타입입니다.
- `class`: 데이터와 동작을 함께 묶고, 기본 접근 제어가 `private`입니다.
- `std::vector`: 동적 배열입니다. 원소 개수가 늘어나면 내부 힙 메모리를 다시 잡을 수 있습니다.
- `std::string`: 문자열을 관리하는 표준 타입입니다. 내부 버퍼 메모리를 자동 관리합니다.
- `const`: 함수가 값을 바꾸지 않는다는 의도를 표현합니다.

## 설계 포인트

외부에서 결제 방법이 바뀌어도 주문 계산 로직이 흔들리지 않게 결제 책임을
`PaymentGateway` 인터페이스로 분리합니다. 이것이 강의 주제 중
`복잡도 관리`, `아키텍처와 설계 구분`, `부수 효과 경계`와 연결됩니다.

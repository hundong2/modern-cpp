# 03. Lifecycle and Memory

## 목표

강의 주제 중 `데이터 흐름과 객체 상태 수명주기`, `잘 정의된 동작`,
`구현 수준 복잡도 관리`를 RAII 예제로 설명합니다.

RAII는 자원을 객체 수명에 묶는 C++의 핵심 관용구입니다. 객체가 생성될 때 자원을
얻고, 소멸될 때 자원을 반납합니다.

## C++ 기초 문법 포인트

- 생성자: 객체가 만들어질 때 호출됩니다.
- 소멸자: 객체 수명이 끝날 때 자동 호출됩니다.
- `std::unique_ptr`: 힙 객체를 단독 소유하는 스마트 포인터입니다.
- `std::make_unique`: 힙에 객체를 만들고 `unique_ptr`로 감쌉니다.
- 이동 `std::move`: 소유권을 다른 객체로 넘깁니다.

## 메모리 관점

- 지역 변수는 보통 스택에 놓이고, 스코프를 벗어나면 자동으로 정리됩니다.
- `new`로 만든 객체는 힙에 놓이며 직접 해제해야 합니다.
- `std::unique_ptr`은 힙 객체의 주소를 들고 있다가 소멸자에서 자동으로 `delete`를 수행합니다.
- 그래서 예외가 발생해도 메모리 누수가 줄어듭니다.

# 05. Concurrency and Constraints

## 목표

강의 주제 중 `동시성`, `병렬성`, `스레딩 모델`, `처리량 제약`,
`공유 상태와 부수 효과`를 작은 큐 예제로 설명합니다.

동시성은 여러 작업의 진행을 다루는 설계 문제입니다. 병렬성은 실제로 여러 작업이
동시에 실행되는 실행 방식입니다. C++에서는 공유 데이터를 직접 다루기 쉽기 때문에
데이터 경합을 막는 구조가 중요합니다.

## C++ 기초 문법 포인트

- `std::thread`: 새 실행 흐름을 만듭니다.
- `std::mutex`: 한 번에 하나의 스레드만 임계 구역에 들어오게 합니다.
- `std::lock_guard`: 스코프가 끝나면 자동으로 뮤텍스를 풉니다.
- `std::condition_variable`: 큐에 데이터가 들어올 때까지 기다립니다.
- `std::optional`: 큐가 닫혀 더 받을 값이 없음을 표현합니다.

## 메모리 관점

여러 스레드가 같은 메모리를 동시에 읽고 쓸 때 동기화가 없으면 데이터 경합이
생깁니다. 데이터 경합은 C++에서 정의되지 않은 동작입니다. 뮤텍스는 공유 메모리에
대한 접근 순서를 만들어 프로그램의 의미를 안정화합니다.

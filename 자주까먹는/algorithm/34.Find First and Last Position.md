# 34. Find First and Last Position of Element in Sorted Array

Given an array of integers nums sorted in non-decreasing order, find the starting and ending position of a given target value.

If target is not found in the array, return [-1, -1].

You must write an algorithm with O(log n) runtime complexity.

## Example 1:

```
Input: nums = [5,7,7,8,8,10], target = 8
Output: [3,4]
```

## Example 2:

```
Input: nums = [5,7,7,8,8,10], target = 6
Output: [-1,-1]
```

## Example 3:

```
Input: nums = [], target = 0
Output: [-1,-1]
``` 

### Constraints:

```
0 <= nums.length <= 105
-109 <= nums[i] <= 109
nums is a non-decreasing array.
-109 <= target <= 109
```

### Algorithm 

    - 반드시 정렬 된 상태여야 한다. 
    - low, high, mid 값을 통한 serach를 진행한다. 
    - mid = low + (high - low)/2 로 이동 한다. 
    - upper bound의 경우 
        - 우측 이동이 기본이므로, left <= target비교를 통해 left 값을 mid + 1로 변경 
        - 같더라도 계속 우측에 값이 있는지 찾아야 한다. 
    - lower bound의 경우 
        - 좌측 이동이 기본, mid 값이 target과 같더라도 좌측으로 이동해서 같은게 또 있는지 찾아야 함 
        - left < target, 일때 같으면 right = mid가 됨. 
    - 수행 결과 lower bound는 return left 값 그대로 사용
    - 수행 결과 upper bound는 return 값에 -1 을 하여 사용 
-<font color="red"> `lower bound` 값이 end() 또는 문자열의 길이와 같거나, target과 다를경우 답이 없다는 뜻 </font>


### Using upper bound, lower bound

```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        auto lower_bound = std::lower_bound(nums.begin(), nums.end(), target);
        if( lower_bound == nums.end() || *lower_bound != target ){
            return {-1, -1};
        } 
        
        auto upper_bound = std::upper_bound(nums.begin(), nums.end(), target);
        int start_idx = std::distance(nums.begin(), lower_bound);
        int end_idx = std::distance(nums.begin(), upper_bound) - 1;

        return {start_idx, end_idx};

    }
};
```

### Using Equal range

```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        auto bounds = std::equal_range(nums.begin(), nums.end(), target);
        if(bounds.first == nums.end() || *bounds.first != target ) return { -1, -1 };
        return {
            (int)distance(nums.begin(), bounds.first),
            (int)distance(nums.begin(), bounds.second) - 1
        };
    }
};
```

### Dotnet 

```csharp
public class Solution {
    public int[] SearchRange(int[] nums, int target) {
        var lower_bd = GetLowerBound(nums, target);
        var upper_bd = GetUpperBound(nums, target);
        if( lower_bd == nums.Length || nums[lower_bd] != target ) return new int[] {-1, -1};
        return new int[] {lower_bd, upper_bd - 1};

    }
    public int GetLowerBound(int[] nums, int target) {
        int left = 0;
        int right = nums.Length;
        int mid = 0;
        while(left < right ){
            mid = left + (right - left) / 2 ;
            if(nums[mid] < target ){
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }
    public int GetUpperBound( int[] nums, int target) {
        int left = 0;
        int right = nums.Length;
        int mid = 0;
        while( left < right ){
            mid = left + (right - left) / 2 ;
            if(nums[mid] <= target ){
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }
}
```

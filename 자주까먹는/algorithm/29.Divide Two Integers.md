# LeetCode 29번 **"Divide Two Integers"** 문제

- 제약 조건 내에서 기본적인 사칙연산(곱셈, 나눗셈, 나머지 연산)을 배제하고 나눗셈을 구현해야 하는 아주 클래식하면서도 깊이 있는 CS(컴퓨터 과학) 문제입니다.

---

### 💡 1. 문제 분석 및 핵심 인사이트

이 문제의 핵심은 **"나눗셈 기호(`/`) 없이 나눗셈을 어떻게 할 것인가?"** 입니다.
나눗셈의 본질은 **"피제수(dividend)에서 제수(divisor)를 몇 번 뺄 수 있는가?"** 입니다.
예를 들어 `10 / 3`은 10에서 3을 3번 빼고 1이 남으므로 몫이 3이 됩니다.

**하지만, 단순히 계속 빼기(Repeated Subtraction)를 하면 어떻게 될까요?**

* $2^{31}-1$ 을 1로 나눈다면, $O(N)$의 시간 복잡도가 걸려 Time Limit Exceeded(시간 초과)가 발생합니다.

**✅ 해결책: 비트 시프트(Bit Shift)를 활용한 지수 탐색(Exponential Search)**
우리는 제수(divisor)를 2배씩($\times 2, \times 4, \times 8 \dots$) 증가시키며 뺄셈을 뭉텅이로 처리할 것입니다.
컴퓨터 구조에서 **왼쪽 비트 시프트(`<< 1`)는 곧 2를 곱하는 것**과 정확히 같은 연산이며, CPU 레벨에서 처리되므로 매우 빠릅니다.

#### 🚨 주의해야 할 Edge Case (32비트 정수 오버플로우)

32비트 부호 있는 정수(Signed Integer)의 범위는 `[-2,147,483,648 ~ 2,147,483,647]` 입니다.
음수(`INT_MIN`)의 절대값이 양수(`INT_MAX`)보다 1 더 큽니다.
만약 `-2147483648 / -1` 을 수행하면 결과는 `+2147483648`이 되어야 하지만, 이는 32비트 양수 최대값을 초과합니다. 문제 조건에 따라 이 경우 `INT_MAX`를 반환해야 합니다.

### 📊 2. 직관적인 알고리즘 시각화 (그림 설명)

`29 / 3` 을 계산한다고 가정해봅시다.

```text
[ 1단계: 29 안에 3이 뭉텅이로 몇 번 들어가는지 찾기 ]
3 << 0 (3 * 1)  = 3    (29보다 작음, 통과)
3 << 1 (3 * 2)  = 6    (29보다 작음, 통과)
3 << 2 (3 * 4)  = 12   (29보다 작음, 통과)
3 << 3 (3 * 8)  = 24   (29보다 작음, 통과)  👉 최대치! 
3 << 4 (3 * 16) = 48   (29보다 큼, 실패)

✅ 첫 번째 결과: 29에서 24(3*8)를 뺍니다. 
   몫(Quotient)에 8을 더합니다. (현재 몫 = 8)
   남은 값: 29 - 24 = 5

[ 2단계: 남은 5 안에 3이 몇 번 들어가는지 찾기 ]
3 << 0 (3 * 1) = 3     (5보다 작음, 통과) 👉 최대치!
3 << 1 (3 * 2) = 6     (5보다 큼, 실패)

✅ 두 번째 결과: 5에서 3(3*1)을 뺍니다.
   몫(Quotient)에 1을 더합니다. (현재 몫 = 8 + 1 = 9)
   남은 값: 5 - 3 = 2

[ 종료 조건 ]
남은 값 2는 제수인 3보다 작으므로 탐색을 종료합니다.
🎯 최종 몫 = 9

```

### 💻 3. 실행 가능한 코드 및 상세 주석

초보자부터 전문가까지 완벽히 이해할 수 있도록 Python과 C++ 예제를 준비했습니다.

#### 🐍 Python 코드 (`solution.py`)

Python은 기본적으로 정수 오버플로우가 없지만, 문제의 32비트 제약 조건을 준수하기 위해 로직을 추가했습니다.

```python
class Solution:
    def divide(self, dividend: int, divisor: int) -> int:
        # 32-bit 부호 있는 정수의 최대/최소값 정의
        INT_MAX = (1 << 31) - 1  # 2147483647
        INT_MIN = -(1 << 31)     # -2147483648
        
        # 1. 예외 처리: 오버플로우가 발생하는 유일한 케이스
        # INT_MIN을 -1로 나누면 INT_MAX + 1이 되어 32비트 범위를 벗어남.
        if dividend == INT_MIN and divisor == -1:
            return INT_MAX
            
        # 2. 결과값의 부호 결정 (XOR 연산 활용)
        # 피제수와 제수 중 하나만 음수일 때 결과가 음수가 됨.
        is_negative = (dividend < 0) ^ (divisor < 0)
        
        # 3. 계산을 쉽게 하기 위해 둘 다 양수(절댓값)로 변환
        abs_dividend = abs(dividend)
        abs_divisor = abs(divisor)
        
        quotient = 0 # 최종 몫을 저장할 변수
        
        # 4. 비트 시프트를 이용한 지수 탐색 (남은 피제수가 제수보다 크거나 같은 동안 반복)
        while abs_dividend >= abs_divisor:
            temp_divisor = abs_divisor
            multiple = 1
            
            # temp_divisor를 2배씩 늘려가며 abs_dividend를 초과하지 않는 최대값을 찾음
            # (temp_divisor << 1) 은 temp_divisor * 2 와 동일
            while abs_dividend >= (temp_divisor << 1):
                temp_divisor <<= 1  # 제수를 2배로 증가
                multiple <<= 1      # 몫의 배수도 2배로 증가 (1 -> 2 -> 4 -> 8...)
                
            # 피제수에서 구한 뭉텅이를 빼줌
            abs_dividend -= temp_divisor
            # 몫에 배수를 누적
            quotient += multiple
            
        # 5. 초기에 구해둔 부호를 적용하여 반환
        return -quotient if is_negative else quotient

# --- 실행 예제 ---
if __name__ == "__main__":
    sol = Solution()
    print(f"10 / 3 = {sol.divide(10, 3)}")     # 예상 결과: 3
    print(f"7 / -3 = {sol.divide(7, -3)}")    # 예상 결과: -2

```

#### ⚙️ C++ 코드 (`solution.cpp`)

C++에서는 엄격한 타입(Type) 관리가 필요합니다. 32비트 환경을 가정하므로 64비트 정수인 `long long`을 사용하여 `INT_MIN`의 절댓값 변환 시 발생하는 오버플로우를 안전하게 처리합니다.

```cpp
#include <iostream>
#include <cmath>
#include <climits> // INT_MAX, INT_MIN을 사용하기 위한 C++ 표준 라이브러리

using namespace std;

class Solution {
public:
    int divide(int dividend, int divisor) {
        // 1. 오버플로우 엣지 케이스 처리
        // -2147483648 / -1 은 +2147483648 이 되어 32비트 표현 범위를 초과함.
        if (dividend == INT_MIN && divisor == -1) {
            return INT_MAX; 
        }

        // 2. 부호 판별 (비트 XOR 연산자 ^ 활용)
        // 둘의 부호가 다르면(하나는 음수, 하나는 양수) 결과는 음수입니다.
        bool isNegative = (dividend < 0) ^ (divisor < 0);

        // 3. 32비트 오버플로우 방지를 위해 long long 자료형으로 캐스팅 후 절댓값 취함
        // std::abs 함수는 <cmath> 라이브러리에 포함되어 있습니다.
        long long absDividend = std::abs((long long)dividend);
        long long absDivisor = std::abs((long long)divisor);

        long long quotient = 0; // 몫을 담을 변수

        // 4. 피제수가 제수보다 크거나 같은 동안 뺄셈 반복
        while (absDividend >= absDivisor) {
            long long tempDivisor = absDivisor;
            long long multiple = 1;

            // 핵심 알고리즘: 제수를 2배씩(<< 1) 증가시키며 최대치 탐색
            while (absDividend >= (tempDivisor << 1)) {
                tempDivisor <<= 1;
                multiple <<= 1;
            }

            // 큰 뭉텅이를 피제수에서 빼기
            absDividend -= tempDivisor;
            // 해당하는 배수만큼 몫에 추가
            quotient += multiple;
        }

        // 5. 최종 결과에 부호 적용
        if (isNegative) {
            quotient = -quotient;
        }

        return (int)quotient;
    }
};

// --- 실행 예제 ---
int main() {
    Solution sol;
    cout << "10 / 3 = " << sol.divide(10, 3) << endl;     // 3
    cout << "7 / -3 = " << sol.divide(7, -3) << endl;     // -2
    cout << "-2147483648 / -1 = " << sol.divide(INT_MIN, -1) << endl; // 2147483647 (INT_MAX)
    return 0;
}

```

### 📝 4. 시간 및 공간 복잡도 분석 (Complexity)

* **시간 복잡도 (Time Complexity): $\mathcal{O}(\log N)$**
* 여기서 $N$은 피제수(dividend)의 크기입니다.
* 안쪽 `while` 루프에서 변수를 2배씩(`<< 1`) 증가시키기 때문에, 최대 31번만 실행됩니다. 바깥쪽 루프 역시 빠르게 줄어드는 피제수 덕분에 상수 시간에 수렴합니다. 따라서 $\mathcal{O}(\log N)$의 매우 빠른 속도로 동작합니다.


* **공간 복잡도 (Space Complexity): $\mathcal{O}(1)$**
* 배열이나 추가적인 자료구조를 사용하지 않고 오직 몇 개의 포인터(정수형 변수)만 메모리에 할당하여 해결하므로 상수 공간만을 요구합니다.

### 🧠 1. 시프트 연산의 수학적 공식

컴퓨터에서 왼쪽 시프트 연산자 `<<`는 단순히 비트를 왼쪽으로 미는 것이 아닙니다. **수학적으로 완벽하게 2의 거듭제곱을 곱하는 것**과 같습니다.

공식으로 표현하면 다음과 같습니다:


$$x \ll k = x \times 2^k$$

이 공식이 왜 중요할까요? 우리가 10진수에서 자릿수를 왼쪽으로 한 칸 옮기면 10이 곱해지듯(예: $3 \rightarrow 30$), 컴퓨터는 2진수를 사용하므로 한 칸 옮길 때마다 2가 곱해집니다.

* $3 \ll 0 = 3 \times 2^0 = 3 \times 1 = 3$
* $3 \ll 1 = 3 \times 2^1 = 3 \times 2 = 6$
* $3 \ll 2 = 3 \times 2^2 = 3 \times 4 = 12$
* $3 \ll 3 = 3 \times 2^3 = 3 \times 8 = 24$

### 📐 2. 나눗셈을 점화식(방정식)으로 이해하기

어떤 수 $N$(피제수, 29)을 $D$(제수, 3)로 나누었을 때의 몫을 $Q$, 나머지를 $R$이라고 하면 다음과 같은 기본 방정식이 성립합니다.


$$N = D \times Q + R$$

여기서 몫 $Q$를 컴퓨터가 좋아하는 이진수(2의 거듭제곱의 합)로 분해해 봅시다. 어떤 숫자든 2의 거듭제곱들의 합으로 표현할 수 있습니다.


$$Q = 2^a + 2^b + 2^c + \dots$$

따라서 식을 이렇게 바꿀 수 있습니다.


$$N = D \times (2^a + 2^b + \dots) + R$$

$$N = (D \times 2^a) + (D \times 2^b) + \dots + R$$

위에서 배운 시프트 공식을 대입하면?


$$N = (D \ll a) + (D \ll b) + \dots + R$$

**💡 알고리즘의 핵심 (점화식 로직):**
우리는 $N$을 넘지 않는 가장 큰 $D \ll k$ 를 찾아서 $N$에서 빼주고, 몫에 $2^k$를 더해주는 과정을 반복(점화)하는 것입니다.

1. $N_{current} \ge D \ll k$ 를 만족하는 **최대 $k$** 를 찾는다.
2. $N_{next} = N_{current} - (D \ll k)$ (남은 값 갱신)
3. $Q_{next} = Q_{current} + 2^k$ (몫 갱신)
4. $N_{next}$ 가 $D$ 보다 작아질 때까지 반복!

### 📊 3. 직관적인 블록 다이어그램 (29 / 3)

29라는 커다란 블록을 3짜리 블록으로 채운다고 상상해 보세요. 한 번에 하나씩 빼면 너무 오래 걸리니, **3을 2배씩 뭉쳐서(시프트)** 가장 큰 덩어리를 먼저 빼내는 겁니다.

```text
전체 크기: 29
[=============================]

1. 3의 2^3(8)배인 24를 먼저 빼냅니다 (가장 큰 덩어리)
[========================] + [=====]
        24 (3 << 3)            남은 5
(이때 몫 Q에 2^3 인 8을 누적)

2. 남은 5에서 3의 2^0(1)배인 3을 빼냅니다.
                     [===] + [==]
                   3(3<<0)  남은 2
(이때 몫 Q에 2^0 인 1을 누적)

남은 2는 3보다 작으므로 종료!
총 몫 = 8 + 1 = 9

```

### 💻 4. 다국어 실행 가능 코드 및 라인별 상세 설명

세 가지 언어로 예제 코드를 작성했습니다. 알고리즘 로직은 수학적 공식을 그대로 코드로 옮긴 것입니다.

#### 🐍 Python (`solution.py`)

```python
class Solution:
    def divide(self, dividend: int, divisor: int) -> int:
        INT_MAX = 2147483647
        INT_MIN = -2147483648
        
        # [라인 6] 오버플로우 엣지 케이스 처리
        if dividend == INT_MIN and divisor == -1:
            return INT_MAX
            
        # [라인 10] 부호 결정 (XOR 연산: 둘 중 하나만 음수면 True)
        is_negative = (dividend < 0) ^ (divisor < 0)
        
        # [라인 13-14] 절댓값으로 변환하여 양수의 나눗셈으로 통일 (점화식 N과 D)
        n = abs(dividend)
        d = abs(divisor)
        
        quotient = 0
        
        # [라인 19] N이 D보다 크거나 같은 동안 반복 (점화식의 종료 조건)
        while n >= d:
            temp_d = d
            multiple = 1 # 2^k 를 나타내는 변수 (초기값 2^0 = 1)
            
            # [라인 24] D << (k+1) 이 N보다 작거나 같은지 확인하며 최대 k를 찾음
            # (temp_d << 1)은 temp_d * 2 와 동일합니다.
            while n >= (temp_d << 1):
                temp_d <<= 1   # D를 2배씩 증가 (D << k)
                multiple <<= 1 # 몫도 2배씩 증가 (2^k)
                
            # [라인 29] N_next = N_current - (D << k)
            n -= temp_d
            # [라인 31] Q_next = Q_current + 2^k
            quotient += multiple
            
        return -quotient if is_negative else quotient

# 실행 코드
if __name__ == "__main__":
    sol = Solution()
    print(f"29 / 3 = {sol.divide(29, 3)}") # 결과: 9

```

#### ⚙️ C++ (`solution.cpp`)

```cpp
#include <iostream>
#include <cmath>     // std::abs 사용
#include <climits>   // INT_MAX, INT_MIN 사용

using namespace std;

class Solution {
public:
    int divide(int dividend, int divisor) {
        // [라인 10] 32비트 정수 오버플로우 예외 처리
        if (dividend == INT_MIN && divisor == -1) return INT_MAX;

        // [라인 13] 부호 식별
        bool isNegative = (dividend < 0) ^ (divisor < 0);

        // [라인 16-17] 32비트 최소값의 절댓값은 최대값을 초과하므로 long long으로 캐스팅
        long long n = std::abs((long long)dividend);
        long long d = std::abs((long long)divisor);
        long long quotient = 0;

        // [라인 21] 점화식 반복문: 피제수가 제수보다 남아있는 동안
        while (n >= d) {
            long long temp_d = d;
            long long multiple = 1;

            // [라인 26] 뺄 수 있는 가장 큰 2의 거듭제곱 덩어리를 찾습니다.
            while (n >= (temp_d << 1)) {
                temp_d <<= 1;   // 공식의 D << k 부분
                multiple <<= 1; // 공식의 2^k 부분
            }

            // [라인 32] 덩어리를 빼고 (나머지 갱신)
            n -= temp_d;
            // [라인 34] 몫을 누적합니다.
            quotient += multiple;
        }

        return isNegative ? -quotient : quotient;
    }
};

// 실행 코드
int main() {
    Solution sol;
    cout << "29 / 3 = " << sol.divide(29, 3) << endl; // 결과: 9
    return 0;
}

```

수학적 공식($x \ll k = x \times 2^k$)과 이진수의 원리를 대입해 보니, 시프트를 통해 뭉텅이로 빼나가는 과정이 훨씬 명확하게 다가오지 않나요? 코드를 읽으실 때 `temp_d <<= 1`을 볼 때마다 "아, $D \times 2^k$ 를 만들고 있구나!"라고 생각하시면 완벽합니다. 

## My Solution

### cpp

```cpp
class Solution {
public:
    int divide(int dividend, int divisor) {
        if(dividend == INT_MIN && divisor == -1) return INT_MAX;
        bool isNegative = (dividend < 0 )^(divisor < 0);
        auto n = std::abs((long long)dividend);
        auto d = std::abs((long long)divisor);
        long long quotient = 0;
        while(n >= d) {
            auto temp_d = d;
            long long multiple = 1;

            while( n >= (temp_d << 1) ){
                temp_d <<= 1; //D << k 
                multiple <<= 1; //2^k
            }
            n -= temp_d;
            quotient += multiple;
        }
        return isNegative ? -quotient : quotient;
    }
};
```

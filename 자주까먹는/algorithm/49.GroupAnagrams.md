# 49. Group Anagrams

Given an array of strings strs, group the anagrams together. You can return the answer in any order.

 

Example 1:

Input: strs = ["eat","tea","tan","ate","nat","bat"]

Output: [["bat"],["nat","tan"],["ate","eat","tea"]]

Explanation:

There is no string in strs that can be rearranged to form "bat".
The strings "nat" and "tan" are anagrams as they can be rearranged to form each other.
The strings "ate", "eat", and "tea" are anagrams as they can be rearranged to form each other.
Example 2:

Input: strs = [""]

Output: [[""]]

Example 3:

Input: strs = ["a"]

Output: [["a"]]

 

Constraints:

1 <= strs.length <= 104
0 <= strs[i].length <= 100
strs[i] consists of lowercase English letters.

## My Solution

### CPP

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        std::unordered_map<string, std::vector<string>> hash_;
        vector<vector<string>> result;
        for(const auto& str: strs){
            auto value = str;
            std::sort(value.begin(), value.end());
            hash_[value].push_back(str);
        }
        for(const auto& value: hash_){
            result.push_back(value.second);
        }
        return result;
    }
};
```

    public IList<IList<string>> GroupAnagrams(string[] strs) {
        Dictionary<string, List<string>> temp = new();
        foreach(var element in strs){
            char[] tempArray = element.ToArray();
            Array.Sort(tempArray);
            var SortedArray = new string(tempArray);
            if( !temp.TryGetValue(SortedArray, out List<string> list)){
                temp[SortedArray] = new List<string>();
            }
            temp[SortedArray].Add(element);
        }
        return temp.Values.ToArray<IList<string>>();
    }
}

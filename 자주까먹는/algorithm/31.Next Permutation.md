# 사전순으로 바로 다음에 오는 순열을 찾는 유명한 알고리즘인 **Next Permutation** 문제 

배열을 직접 조작하여 $O(1)$의 추가 공간만으로 다음 순열을 만들어야 하므로, 수학적 규칙성을 파악하는 것이 핵심입니다.

---

## 1. 알고리즘 설계 및 동작 원리

사전순으로 다음 배열을 만들려면, **최대한 오른쪽(뒤쪽)에 있는 숫자를 변경**해야 값의 증가폭을 최소화할 수 있습니다.

1. **탐색 (Find Pivot):** 오른쪽에서 왼쪽으로 이동하며 처음으로 숫자가 작아지는 지점(`nums[i] < nums[i+1]`)을 찾습니다. 이 `i`가 교체할 기준점(Pivot)입니다.
2. **교체 대상 탐색 (Find Successor):** 다시 오른쪽 끝에서 왼쪽으로 이동하며 `nums[i]`보다 큰 첫 번째 숫자(`nums[j]`)를 찾습니다.
3. **스왑 (Swap):** `nums[i]`와 `nums[j]`의 자리를 바꿉니다.
4. **뒤집기 (Reverse):** `i`의 오른쪽 부분(`i+1`부터 끝까지)은 내림차순 정렬된 상태이므로, 이를 완전히 뒤집어(오름차순) 가장 작은 수열로 만듭니다.

---

## 2. 직관적인 시각화

배열 `[1, 3, 5, 4, 2]`의 다음 순열을 찾는 과정을 그래프로 보겠습니다.

```text
       [5] (꼭대기)
      /   \
    [3]   [4]
    /       \
  [1]       [2]

```

* **Step 1:** 뒤에서부터 오름차순이 깨지는 지점 탐색 $\rightarrow$ `3` (인덱스 1)
* **Step 2:** 뒤에서부터 `3`보다 큰 첫 번째 숫자 탐색 $\rightarrow$ `4` (인덱스 3)
* **Step 3:** 둘을 스왑 $\rightarrow$ `[1, 4, 5, 3, 2]`
* **Step 4:** `4`의 오른쪽 구간 `[5, 3, 2]`를 뒤집기 $\rightarrow$ `[2, 3, 5]`
* **결과:** `[1, 4, 2, 3, 5]`

## 3. 언어별 실행 코드 및 라인별 해설

### Python (.py)

```python
class Solution:
    def nextPermutation(self, nums: list[int]) -> None:
        # 배열의 길이를 구합니다.
        n = len(nums)
        i = n - 2
        
        # Step 1: 오른쪽에서 왼쪽으로 탐색하며 오름차순이 꺾이는 첫 번째 인덱스 i를 찾습니다.
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
            
        if i >= 0:
            j = n - 1
            # Step 2: i보다 오른쪽에 있는 숫자 중, nums[i]보다 큰 첫 번째 숫자를 찾습니다.
            while nums[j] <= nums[i]:
                j -= 1
            # Step 3: 찾은 두 숫자의 위치를 바꿉니다.
            nums[i], nums[j] = nums[j], nums[i]
            
        # Step 4: i 이후의 모든 숫자를 뒤집어 오름차순(가장 작은 순열 상태)으로 만듭니다.
        # i가 -1이라면(전체 내림차순) 배열 전체가 뒤집힙니다.
        left, right = i + 1, n - 1
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1

```

### C++ (.cpp)

C++은 표준 라이브러리인 `<algorithm>`에 동일한 동작을 하는 `std::next_permutation` 함수가 이미 존재하여 강력하고 간결하게 작성할 수 있습니다.

```cpp
#include <vector>
#include <algorithm> // 알고리즘 표준 라이브러리 사용

class Solution {
public:
    void nextPermutation(std::vector<int>& nums) {
        // C++ STL의 next_permutation은 문제의 요구사항과 100% 일치하게 동작합니다.
        // in-place로 다음 순열을 만들며, 마지막 순열일 경우 오름차순 정렬 후 false를 반환합니다.
        std::next_permutation(nums.begin(), nums.end());
    }
};

```

### C# (.csx)

```csharp
public class Solution {
    public void NextPermutation(int[] nums) {
        int n = nums.Length;
        int i = n - 2;
        
        // 1. 피벗 인덱스 찾기
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }
        
        if (i >= 0) {
            int j = n - 1;
            // 2. 바꿀 대상 찾기
            while (nums[j] <= nums[i]) {
                j--;
            }
            // 3. 값 스왑을 위해 임시 변수 사용
            int temp = nums[i];
            nums[i] = nums[j];
            nums[j] = temp;
        }
        
        // 4. 나머지 부분 배열 뒤집기 (표준 내장 메서드 활용)
        // Array.Reverse(배열, 시작 인덱스, 뒤집을 길이)
        Array.Reverse(nums, i + 1, n - i - 1);
    }
}

```

## 4. 복잡도 정리

| 항목 | 복잡도 | 설명 |
| --- | --- | --- |
| **시간 복잡도** | $O(N)$ | 배열을 최악의 경우 2~3번 순회(탐색 및 뒤집기)하므로 선형 시간을 가집니다. |
| **공간 복잡도** | $O(1)$ | 추가적인 배열 할당 없이 포인터(인덱스) 조작만으로 교환하므로 상수 공간을 사용합니다. |

```cpp
class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int nums_size = nums.size();
        int i = nums_size - 2;
        
        while(i >= 0 && nums[i] >= nums[i+1]){
            i--;
        }
        if( i >= 0 ){
            auto j = nums_size - 1;
            while(j >= 0 && nums[i] >= nums[j]) {
                j--;
            }
            std::swap(nums[i], nums[j]);
        }


        std::reverse(nums.begin() + i + 1, nums.end());
    }
};
```

## 25. Reverse Nodes in k-Group

Given the head of a linked list, reverse the nodes of the list k at a time, and return the modified list.

k is a positive integer and is less than or equal to the length of the linked list. If the number of nodes is not a multiple of k then left-out nodes, in the end, should remain as it is.

You may not alter the values in the list's nodes, only nodes themselves may be changed.

 

### Example 1:

```
Input: head = [1,2,3,4,5], k = 2
Output: [2,1,4,3,5]
```

### Example 2:

```
Input: head = [1,2,3,4,5], k = 3
Output: [3,2,1,4,5]
```

### Constraints:

```
The number of nodes in the list is n.
1 <= k <= n <= 5000
0 <= Node.val <= 1000
```

Follow-up: Can you solve the problem in O(1) extra memory space?

## My Solution 

### Csharp

```csharp
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     public int val;
 *     public ListNode next;
 *     public ListNode(int val=0, ListNode next=null) {
 *         this.val = val;
 *         this.next = next;
 *     }
 * }
 */
public class Solution {
    public ListNode ReverseKGroup(ListNode head, int k) {
        if( head == null || k == 1) return head;
        ListNode dummy = new(0);
        ListNode curr = head;
        int count = 0;
        while(curr != null){
            curr = curr.next;
            count++;
        }
        dummy.next = head;
        ListNode prev = dummy;
        while(count >= k) {
            curr = prev.next;
            ListNode nxt = curr.next;
            for(int i = 1; i < k; i++ ){
                curr.next = nxt.next;
                nxt.next = prev.next;
                prev.next = nxt;
                nxt = curr.next;
            }
            prev = curr;
            count -= k;
        }
        return dummy.next;
    }
}
```

### CPP

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseKGroup(ListNode* head, int k) {
        ListNode* curr = head;
        int cnt = 0;
        while(curr != nullptr ){
            curr = curr->next;
            cnt++;
        }
        ListNode dummy(0);
        dummy.next = head;
        ListNode* prev = &dummy;
        while(cnt >= k){
            curr = prev->next;
            ListNode* nxt = curr->next;
            for(int i = 1;i < k; i++){
                curr->next = nxt->next;
                nxt->next = prev->next;
                prev->next = nxt;
                nxt = curr->next;
            }
            prev = curr;
            cnt -= k;
        }
        return dummy.next;
    }
};
```


## Contents

$k$-Group 문제는 "일정 개수마다 끊어서 뒤집고 다시 이어붙이는" 복잡한 제어가 필요했지만, 전체를 뒤집는 문제는 훨씬 단순합니다. 앞서 보신 `prev`, `curr`, `nxt` 3개의 포인터가 **리스트의 끝(null)에 도달할 때까지 한 칸씩 전진하며 방향만 반대로 꺾어주면** 됩니다.

---

## 🔄 포인터 전진 시각화 (전체 뒤집기)

초기 상태: `1 -> 2 -> 3 -> null`
전체를 뒤집을 때는 `Dummy` 노드가 굳이 필요하지 않습니다. `prev`를 `null`로 시작하는 것이 핵심 테크닉입니다.

1. **초기 셋업:** prev는 null, curr는 1(Head)에서 시작합니다..
```text
prev        curr        nxt
[null]      [ 1 ]  ->  [ 2 ]  ->  [ 3 ]  ->  null

```

* `curr`의 연결 방향을 `prev` 쪽으로 꺾어줄 준비를 합니다.


2. **1번 노드 방향 꺾기:** nxt를 저장하고, curr의 방향을 뒤집습니다..
```text
prev        curr        nxt
[null]  <-  [ 1 ]      [ 2 ]  ->  [ 3 ]  ->  null

```

* `curr.next = prev`를 실행하여 1번 노드가 `null`을 가리키게 합니다 (새로운 꼬리가 됨).
* 이때 `2`번 노드로 가는 길이 끊어지지 않게 미리 `nxt = curr.next`로 저장해 둔 것입니다.


3. **다음 노드로 이동:** prev와 curr를 모두 한 칸씩 우측으로 전진시킵니다..
```text
            prev        curr      nxt (다음에 할당됨)
[null]  <-  [ 1 ]       [ 2 ]  ->  [ 3 ]  ->  null

```

* `prev = curr`
* `curr = nxt`


4. **2번, 3번 노드 방향 꺾기:** 동일한 작업을 반복합니다..
이 과정을 `curr`가 `null`이 될 때까지 계속 반복하면 최종적으로 아래 그림이 됩니다.

```text
                                     prev       curr
[null]  <-  [ 1 ]  <-  [ 2 ]  <-  [ 3 ]       [null]

```

* 루프가 종료되면 **`prev`가 가리키는 노드(`3`)가 새로운 Head**가 됩니다!

## 💻 언어별 실전 코드 (라인 단위 주석)

알고리즘의 정석인 $O(1)$ 공간 복잡도와 $O(n)$ 시간 복잡도를 가지는 In-place 뒤집기입니다.

### C# (`.csx` / `.cs`)

```csharp
public class Solution {
    public ListNode ReverseList(ListNode head) {
        // 이전 노드를 추적할 포인터. 시작할 때는 이전 노드가 없으므로 null입니다.
        ListNode prev = null; 
        // 현재 처리 중인 노드
        ListNode curr = head; 
        
        // curr가 리스트의 끝(null)에 도달할 때까지 반복합니다.
        while (curr != null) {
            // 1. 다음 노드(nxt)를 임시로 안전하게 저장해 둡니다 (연결이 끊기지 않도록).
            ListNode nxt = curr.next;
            
            // 2. 현재 노드의 화살표 방향을 '이전 노드(prev)'로 휙 꺾습니다! (핵심)
            curr.next = prev;
            
            // 3. prev 포인터를 현재 노드 위치로 한 칸 전진시킵니다.
            prev = curr;
            
            // 4. curr 포인터도 아까 저장해둔 다음 노드 위치로 한 칸 전진시킵니다.
            curr = nxt;
        }
        
        // 반복이 끝나면 curr은 null이고, prev가 새로운 머리(Head) 노드를 가리키고 있습니다.
        return prev;
    }
}

```

### C++ (`.cpp`)

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr; // C++의 null 포인터는 nullptr을 사용합니다.
        ListNode* curr = head;
        
        while (curr != nullptr) {
            ListNode* nxt = curr->next; // 1. 다음 노드 주소 백업
            
            curr->next = prev;          // 2. 링크 방향 뒤집기
            
            prev = curr;                // 3. prev 포인터 한 칸 전진
            curr = nxt;                 // 4. curr 포인터 한 칸 전진
        }
        
        return prev; // 리버스된 리스트의 새로운 Head
    }
};

```

### Python (`.py`)

파이썬은 다중 할당(Tuple Unpacking)을 지원하므로, 임시 변수 `nxt` 없이 한 줄의 코드로 매우 우아하게 작성할 수 있습니다.

```python
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev = None
        curr = head
        
        while curr:
            # 우변이 먼저 평가된 후 좌변에 동시 할당되므로 임시 변수가 필요 없습니다!
            # 1. curr.next(현재 노드의 다음)를 prev로 연결하고
            # 2. prev를 curr 위치로 이동하고
            # 3. curr을 기존의 curr.next(다음 노드)로 이동합니다.
            curr.next, prev, curr = prev, curr, curr.next
            
        return prev

```

$k$-Group에 비하면 코드가 훨씬 간결하죠? 이 뼈대 코드를 완벽히 이해하시면 어떤 연결 리스트 뒤집기 문제가 나와도 응용할 수 있습니다.

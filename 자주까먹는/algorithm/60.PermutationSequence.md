# 60. Permutation Sequence

The set [1, 2, 3, ..., n] contains a total of n! unique permutations.

By listing and labeling all of the permutations in order, we get the following sequence for n = 3:

"123"
"132"
"213"
"231"
"312"
"321"
Given n and k, return the kth permutation sequence.

 

Example 1:

Input: n = 3, k = 3
Output: "213"
Example 2:

Input: n = 4, k = 9
Output: "2314"
Example 3:

Input: n = 3, k = 1
Output: "123"
 

Constraints:

1 <= n <= 9
1 <= k <= n!

## My Solution

```cpp
class Solution {
public:
    string getPermutation(int n, int k) {
        std::string result{};
        std::vector<int> numbers;
        int fact = 1;
        for(int i = 1;i <= n; i++){
            numbers.push_back(i);
            fact *= i;
        }
        k -= 1;
        for(int i = n; i > 0; --i){
            fact /= i; //n -1 factorial
            int idx = k / fact;
            result += std::to_string(numbers[idx]);
            numbers.erase(numbers.begin() + idx);
            k %= fact;
        }

        return result;
    }
};
```


### 💡 1. 알고리즘 직관적 이해 (그림 설명)

$n = 4, k = 9$인 Example 2를 살펴봅시다.
1, 2, 3, 4로 만들 수 있는 순열은 총 $4! = 24$개입니다.

첫 번째 자리에 어떤 숫자가 오느냐에 따라 순열을 4개의 그룹으로 나눌 수 있습니다. 각 그룹에 속하는 순열의 개수는 남은 3개 숫자의 순열인 $3! = 6$개입니다.

```text
[전체 24개의 순열 - 각 그룹당 6개(3!)씩 배분]
그룹 0 (1로 시작): 1번째 ~ 6번째 순열 (index: 0 ~ 5)
그룹 1 (2로 시작): 7번째 ~ 12번째 순열 (index: 6 ~ 11)   <-- k=9 는 여기에 속함!
그룹 2 (3로 시작): 13번째 ~ 18번째 순열 (index: 12 ~ 17)
그룹 3 (4로 시작): 19번째 ~ 24번째 순열 (index: 18 ~ 23)

```

우리가 찾는 것은 9번째(0-based index로는 **8**) 순열입니다.

1. **첫 번째 숫자 결정:**
* 인덱스 $8$을 그룹 크기 $3!(6)$으로 나눕니다. $\rightarrow 8 / 6 = 1$.
* 남은 숫자 `[1, 2, 3, 4]` 중 인덱스 1번은 '2'입니다. (첫 숫자 '2' 확정!)
* 다음 계산을 위해 숫자 2를 지우고, 인덱스를 업데이트합니다. $\rightarrow 8 \pmod 6 = 2$. (이제 남은 숫자들로 만드는 조합 중 인덱스 2번을 찾아야 함)


2. **두 번째 숫자 결정:**
* 남은 숫자: `[1, 3, 4]`
* 다음 그룹 크기는 $2! = 2$입니다.
* 인덱스 $2 / 2 = 1$. 남은 숫자 중 1번 인덱스는 '3'입니다. (두 번째 숫자 '3' 확정!)
* 업데이트: $2 \pmod 2 = 0$.


3. **세 번째 숫자 결정:**
* 남은 숫자: `[1, 4]`
* 다음 그룹 크기는 $1! = 1$입니다.
* 인덱스 $0 / 1 = 0$. 남은 숫자 중 0번 인덱스는 '1'입니다. (세 번째 숫자 '1' 확정!)
* 업데이트: $0 \pmod 1 = 0$.


4. **네 번째 숫자 결정:**
* 남은 숫자: `[4]`
* 남은 숫자가 하나뿐이므로 **'4'** 확정!



최종 결과: **"2314"**

### 💻 2. Python 3 구현 (실행 가능한 `.py` 형태)

Python의 강력한 표준 라이브러리인 `math`를 사용하여 팩토리얼을 쉽게 계산합니다.

```python
import math

def getPermutation(n: int, k: int) -> str:
    # 1. 사용할 숫자들을 리스트로 초기화합니다. [1, 2, ..., n]
    numbers = list(range(1, n + 1))
    
    # 2. 0-based 인덱스를 사용하기 위해 k에서 1을 뺍니다.
    k -= 1
    
    # 3. 결과를 담을 리스트 (나중에 문자열로 조인)
    result = []
    
    # 4. n부터 1까지 감소시키며 각 자리의 숫자를 결정합니다.
    for i in range(n, 0, -1):
        # 5. 현재 자리 숫자를 결정하기 위한 그룹의 크기 (i-1)!
        fact = math.factorial(i - 1)
        
        # 6. 현재 k가 속한 그룹의 인덱스를 계산합니다.
        idx = k // fact
        
        # 7. numbers 리스트에서 해당 인덱스의 숫자를 뽑아내(pop) 결과에 추가합니다.
        # pop()은 리스트에서 요소를 제거함과 동시에 반환하는 내장 함수입니다.
        result.append(str(numbers.pop(idx)))
        
        # 8. 다음 자리 숫자를 구하기 위해 k를 업데이트합니다.
        k %= fact
        
    # 9. 리스트에 모인 문자들을 하나의 문자열로 합쳐서 반환합니다.
    return "".join(result)

# 실행 예제
if __name__ == "__main__":
    print(getPermutation(3, 3)) # 예상 출력: "213"
    print(getPermutation(4, 9)) # 예상 출력: "2314"

```

### 💻 3. C++ 구현 (실행 가능한 `.cpp` 형태)

C++에서는 `std::vector`와 `std::string`을 적극 활용하며, 동적 배열의 원소 제거를 위해 `erase` 멤버 함수를 사용합니다.

```cpp
#include <iostream>
#include <vector>
#include <string>

using namespace std;

string getPermutation(int n, int k) {
    vector<int> numbers;
    int fact = 1;
    
    // 1. 숫자 배열 초기화 및 n! 계산
    for(int i = 1; i <= n; ++i) {
        numbers.push_back(i); // [1, 2, ..., n]
        fact *= i;            // fact는 마지막에 n!이 됨
    }
    
    // 2. 0-based index로 변환
    k -= 1;
    string result = "";
    
    // 3. n번 반복하면서 각 자리수를 찾아냅니다.
    for(int i = n; i > 0; --i) {
        // 4. (i-1)! 값을 구합니다. 이전 팩토리얼 값에서 i를 나누면 됩니다.
        fact /= i;
        
        // 5. 숫자를 뽑아낼 인덱스 도출
        int idx = k / fact;
        
        // 6. std::to_string을 통해 정수를 문자열로 변환하여 결과에 덧붙임
        result += to_string(numbers[idx]);
        
        // 7. 사용한 숫자를 벡터에서 제거 (표준 라이브러리 함수 erase 사용)
        numbers.erase(numbers.begin() + idx);
        
        // 8. 남은 순열 번호 갱신
        k %= fact;
    }
    
    return result;
}

// 실행 예제
int main() {
    cout << getPermutation(3, 3) << endl; // 213
    cout << getPermutation(4, 9) << endl; // 2314
    return 0;
}

```

### 💻 4. C# 구현 (실행 가능한 `.csx` 형태)

C#에서는 메모리 낭비를 줄이기 위해 문자열 결합 시 `StringBuilder` 표준 클래스를 적극 활용하는 것이 Best Practice입니다.

```csharp
using System;
using System.Collections.Generic;
using System.Text;

public class Solution {
    public string GetPermutation(int n, int k) {
        // 1. 제네릭 컬렉션 List<int>를 사용하여 숫자 후보군 초기화
        List<int> numbers = new List<int>();
        int fact = 1;
        
        for(int i = 1; i <= n; i++) {
            numbers.Add(i);
            fact *= i;
        }
        
        // 2. 0-based 인덱스로 맞춤
        k -= 1;
        
        // 3. 잦은 문자열 변경에 최적화된 StringBuilder 사용
        StringBuilder result = new StringBuilder();
        
        // 4. 각 자릿수에 들어갈 숫자 탐색
        for(int i = n; i > 0; i--) {
            // (i-1)! 구하기
            fact /= i;
            
            int idx = k / fact;
            
            // 5. StringBuilder에 숫자 추가
            result.Append(numbers[idx]);
            
            // 6. 사용한 숫자는 리스트에서 제거 (RemoveAt)
            numbers.RemoveAt(idx);
            
            // 7. k 갱신
            k %= fact;
        }
        
        // 8. 완성된 문자열 반환
        return result.ToString();
    }
}

// 실행 예제
Solution sol = new Solution();
Console.WriteLine(sol.GetPermutation(3, 3)); // 213
Console.WriteLine(sol.GetPermutation(4, 9)); // 2314

```

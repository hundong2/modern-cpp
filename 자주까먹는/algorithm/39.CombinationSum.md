# 39. Combination Sum

Given an array of distinct integers candidates and a target integer target, return a list of all unique combinations of candidates where the chosen numbers sum to target. You may return the combinations in any order.

The same number may be chosen from candidates an unlimited number of times. Two combinations are unique if the frequency of at least one of the chosen numbers is different.

The test cases are generated such that the number of unique combinations that sum up to target is less than 150 combinations for the given input.

 

Example 1:

Input: candidates = [2,3,6,7], target = 7
Output: [[2,2,3],[7]]
Explanation:
2 and 3 are candidates, and 2 + 2 + 3 = 7. Note that 2 can be used multiple times.
7 is a candidate, and 7 = 7.
These are the only two combinations.
Example 2:

Input: candidates = [2,3,5], target = 8
Output: [[2,2,2,2],[2,3,3],[3,5]]
Example 3:

Input: candidates = [2], target = 1
Output: []
 

Constraints:

1 <= candidates.length <= 30
2 <= candidates[i] <= 40
All elements of candidates are distinct.
1 <= target <= 40

### My Solution

#### Csharp

```csharp
public class Solution {
    public IList<IList<int>> CombinationSum(int[] candidates, int target) {
        List<IList<int>> result = new();
        var path = new List<int>();
        backtracking(ref candidates, ref result, path, target, 0);
        return result;
    }
    public void backtracking(ref int[] candidates, ref List<IList<int>> result, List<int> sumVal, int start, int idx){
        if( start == 0 ){
            result.Add(new List<int>(sumVal));
            return;
        } else if ( start < 0 ){
            return;
        }
        for(int i = idx; i < candidates.Count(); i++){
                sumVal.Add(candidates[i]);
                backtracking(ref candidates, ref result, sumVal, start - candidates[i], i);
                sumVal.RemoveAt(sumVal.Count - 1);
        }
    } 
}
```

#### CPP

```cpp
class Solution {
public:
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        vector<vector<int>> result;
        vector<int> value;
        backtracking(candidates, result, value, target, 0);
        return result;
    }
private: 
    void backtracking(vector<int>& candidates, vector<vector<int>>& result, vector<int> value, int sum, int idx){
        if(sum == 0 ){
            result.push_back(value);
            return;
        } else if(sum < 0 ) {
            return;
        }
        for(int i = idx; i < candidates.size(); i++){
            if(sum - candidates[i] < 0 ) continue;
            value.push_back(candidates[i]);
            backtracking(candidates, result, value, sum - candidates[i], i);
            value.pop_back();
        }
    }
};
```

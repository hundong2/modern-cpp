# 값 범주·참조·이동

lvalue는 정체성이 있는 식, prvalue는 값을 계산하는 식, xvalue는 자원을 재사용할 수 있는 정체성 있는 식이다. rvalue는 prvalue와 xvalue를 묶는 범주다. “이름이 있으면 lvalue”는 입문용 힌트일 뿐 완전한 정의가 아니다.

`std::move(x)`는 `x`를 xvalue로 바꾸는 캐스트다. 데이터를 옮기지 않는다. 이후 오버로드 해석이 이동 생성자/이동 대입을 선택할 기회를 준다. 이동된 객체는 **유효하지만 값은 미지정** 상태여야 하며, 파괴하거나 새 값을 대입할 수 있다.

`T&&`는 문맥에 따라 rvalue reference 또는 forwarding reference가 된다. 템플릿 타입 추론이 결합된 `T&&`에서만 후자의 규칙이 적용된다.

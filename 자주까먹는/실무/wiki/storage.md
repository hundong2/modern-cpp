# 캐시·DB·커넥션 풀

Redis는 메모리 중심 자료 구조 서버로 세션·캐시·rate limit 등에 쓰인다. MySQL 같은 RDBMS는 트랜잭션과 영속 관계 데이터를 담당한다. 네트워크/DB 호출을 이벤트 루프에서 동기 수행하면 전체 연결 처리가 멈출 수 있으므로 별도 비동기 클라이언트나 제한된 작업 풀로 격리한다.

connection pool은 매 요청의 연결 설정 비용을 줄이지만 무제한 병렬성을 제공하지 않는다. 풀 크기는 DB가 감당할 동시 쿼리 수와 backpressure 정책으로 정한다. Prepared statement는 값과 SQL 구조를 분리해 injection 방어에 도움을 주지만 권한 최소화와 입력 검증도 필요하다.

# 메모리·스코프·수명

프로세스의 가상 주소 공간에는 보통 코드, 정적 저장 영역, 스택, 동적 할당 영역이 있다. C++ 표준은 구현의 정확한 물리 배치를 강제하지 않는다. 중요한 구분은 [저장 기간](https://en.cppreference.com/w/cpp/language/storage_duration)과 객체 수명이다.

- 자동 저장 기간: 블록 진입 시 생기고 탈출 시 파괴되는 지역 객체.
- 정적 저장 기간: 프로그램 수명 동안 존재하는 전역/정적 객체.
- 동적 저장 기간: allocator가 확보하고 소유 객체가 해제하는 저장소.

컨테이너 재할당, 객체 파괴, 이동 후에는 포인터·참조·반복자가 무효화될 수 있다. 유효성 규칙을 API 문서에서 확인해야 한다.

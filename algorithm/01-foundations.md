# 01. 복잡도와 문제 해결 기초

## 알고리즘과 자료구조

- **알고리즘**은 입력을 원하는 출력으로 바꾸는 유한한 절차다.
- **자료구조**는 데이터를 저장하고 접근하는 규칙이다.
- 같은 알고리즘도 자료구조 선택에 따라 속도가 크게 달라진다. 예를 들어 BFS는 앞에서 꺼내고 뒤에 넣는 FIFO(First In, First Out, 선입선출) 큐가 필요하다.

## 시간·공간 복잡도

Big-O는 입력 크기 `n`이 커질 때 연산량의 증가율의 상한을 표현한다. 상수와 낮은 차수는 생략한다.

| 복잡도 | 전형적인 예 | `n`이 커질 때 |
|---|---|---|
| `O(1)` | 배열 인덱스 접근, 해시 평균 조회 | 거의 일정 |
| `O(log n)` | 이진 탐색, 균형 트리 연산 | 매우 완만 |
| `O(n)` | 한 번 순회 | 선형 증가 |
| `O(n log n)` | 비교 기반 효율 정렬 | 큰 입력에도 흔히 가능 |
| `O(n²)` | 모든 쌍 비교 | 수만 개부터 대개 부담 |
| `O(2^n)`, `O(n!)` | 부분집합/순열 완전 탐색 | 작은 `n`만 가능 |

Big-O는 실제 시간을 보장하지 않는다. 캐시 지역성, 언어 런타임, 입력 분포, 상수 비용도 중요하다. 또한 최악·평균·상각(amortized) 복잡도를 구분한다. 동적 배열의 한 번의 확장은 `O(n)`이지만 반복 `push`는 보통 상각 `O(1)`이다.

공간 복잡도에는 입력 외에 쓰는 보조 배열, 큐, 재귀 호출 스택을 포함한다. 깊이 `n`인 재귀 DFS는 호출 스택 `O(n)`을 쓸 수 있다.

## 정확성: 전제 조건, 불변식, 종료

알고리즘을 외우는 대신 다음 세 문장을 작성한다.

1. **전제 조건**: 이진 탐색의 입력은 정렬되어 있다.
2. **불변식(invariant)**: 반복 중에도 답이 존재한다면 현재 탐색 구간 안에 있다.
3. **종료와 결과**: 구간이 매번 줄어 결국 비거나 답을 찾는다.

반례는 전제 조건을 공격해서 만든다. 정렬되지 않은 배열에 이진 탐색, 음수 간선에 다익스트라, 음수가 섞인 합에 단순 슬라이딩 윈도를 적용하면 왜 깨지는지 확인한다.

## 반복과 재귀

재귀 함수에는 반드시 다음이 있어야 한다.

- 기저 조건: 더 호출하지 않고 답을 반환하는 경우
- 진행: 문제가 기저 조건에 가까워지도록 크기를 줄이는 호출
- 결합: 작은 문제의 답으로 현재 답을 만드는 방법

트리처럼 구조 자체가 재귀적이면 재귀 구현이 자연스럽다. 그래프가 매우 깊거나 입력 크기를 통제할 수 없다면 명시적인 `stack`을 써서 호출 스택 초과를 피한다. Python은 특히 기본 재귀 깊이가 작으므로 반복 DFS가 안전한 경우가 많다.

## 문제 풀이 체크리스트

1. 입력 크기와 값 범위를 보고 허용 복잡도와 오버플로 가능성을 정한다.
2. 정렬 여부, 간선 가중치, 연속 구간 여부 같은 구조를 찾는다.
3. 완전 탐색을 먼저 정의하고 중복 계산이나 불필요한 탐색을 찾는다.
4. 자료구조와 알고리즘을 선택하고 불변식을 한 문장으로 쓴다.
5. 빈 입력, 원소 하나, 중복, 최대/최소값, 연결되지 않은 그래프를 시험한다.
6. 시간과 공간 복잡도를 각각 계산한다.

## 언어별 비용 감각

- C++: 값 복사와 객체 수명, 반복자 무효화, 정수 오버플로와 배열 경계를 주의한다.
- C#: 배열/값 형식과 클래스/참조 형식 차이, 가비지 컬렉션, LINQ의 숨은 열거·할당을 의식한다.
- Python: 큰 정수는 자동 확장되지만 객체와 해시 구조의 상수 비용이 크다. 슬라이스는 대개 새 리스트를 만든다.

# 03. 탐색과 정렬

## 선형 탐색과 이진 탐색

선형 탐색은 처음부터 하나씩 비교하므로 정렬이 필요 없고 `O(n)`이다. 이진 탐색은 정렬된 구간을 절반씩 버려 `O(log n)`이다.

이진 탐색에서 가장 안전한 형태 중 하나는 반열린 구간 `[left, right)`다.

```text
left = 0, right = length
while left < right:
    mid = left + (right - left) // 2
    if array[mid] < target: left = mid + 1
    else: right = mid
return left  // target 이상인 첫 위치(lower_bound)
```

이 코드는 값의 존재 여부뿐 아니라 `target 이상인 첫 위치`를 구한다. 종료 후 인덱스가 범위 안이고 값이 같은지 확인하면 검색 결과가 된다. `mid = left + (right-left)/2`는 고정 폭 정수에서 `left+right` 오버플로를 피한다.

### 답에 대한 이진 탐색

정답 후보 `x`에 대해 `가능한가(x)`가 `false...false, true...true`처럼 단조라면 값의 범위를 이진 탐색할 수 있다. 예: 제한 시간 안에 처리 가능한 최소 속도. 배열이 정렬되어 있을 필요는 없지만 판정 함수가 단조여야 한다.

## 정렬 알고리즘 비교

| 알고리즘 | 평균 | 최악 | 추가 공간 | 안정성 | 핵심 |
|---|---:|---:|---:|---|---|
| 선택 정렬 | `O(n²)` | `O(n²)` | `O(1)` | 보통 불안정 | 매번 최솟값 선택 |
| 삽입 정렬 | `O(n²)` | `O(n²)` | `O(1)` | 안정 | 거의 정렬된 작은 입력에 좋음 |
| 병합 정렬 | `O(n log n)` | `O(n log n)` | `O(n)` | 안정 | 나누고 정렬한 두 구간 병합 |
| 퀵 정렬 | `O(n log n)` | `O(n²)` | 재귀 스택 | 보통 불안정 | 피벗 기준 분할 |
| 힙 정렬 | `O(n log n)` | `O(n log n)` | `O(1)` | 불안정 | 힙 최댓값 반복 추출 |
| 계수 정렬 | `O(n+k)` | `O(n+k)` | `O(k)` | 구현에 따라 | 값 범위 `k`가 작을 때 |

안정 정렬은 같은 키를 가진 원소의 원래 상대 순서를 보존한다. `나이`로 정렬하되 같은 나이의 가입 순서를 유지해야 할 때 중요하다.

실무에서는 표준 정렬을 기본으로 사용한다. C++ `std::sort`, C# `Array.Sort`, Python `sorted`/`list.sort`는 잘 최적화되어 있다. 직접 구현은 불변식과 복잡도를 배우기 위한 것이다.

## 빠른 선택과 부분 정렬

- 최솟값 하나: 한 번 순회 `O(n)` 또는 유지 중인 최소 힙
- 가장 작은 `k`개: 입력/`k` 크기에 따라 크기 `k` 최대 힙 `O(n log k)` 또는 Quickselect 평균 `O(n)`
- 스트림에서 계속 상위 `k`개: 크기 `k` 힙
- 여러 번 순위 질의: 한 번 정렬 후 인덱스 접근

## 흔한 실수

- 정렬 전 인덱스가 의미 있는데 원본을 제자리 정렬한다.
- 비교 함수가 일관된 엄격한 순서를 만들지 않는다.
- `lower_bound`(이상 첫 위치)와 `upper_bound`(초과 첫 위치)를 혼동한다.
- 재귀 퀵 정렬에서 같은 값이 많을 때 구간이 줄지 않는다.

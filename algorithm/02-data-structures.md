# 02. 핵심 자료구조

## 선택표

| 자료구조 | 강점 | 약점 | 대표 용도 |
|---|---|---|---|
| 배열/동적 배열 | 인덱스 `O(1)`, 캐시 친화적 | 중간 삽입·삭제 `O(n)` | 순차 데이터, DP 표 |
| 연결 리스트 | 위치를 알 때 연결 변경 `O(1)` | 탐색 `O(n)`, 캐시 불리 | 안정된 노드 연결이 중요할 때 |
| 스택 | 마지막 원소 삽입/삭제 `O(1)` | 중간 접근 불가 | DFS, 괄호, 실행 취소 |
| 큐/덱 | 양 끝 연산 `O(1)` | 임의 접근에 부적합 | BFS, 작업 대기열, 슬라이딩 윈도 |
| 해시 맵/집합 | 평균 조회·삽입 `O(1)` | 순서 없음, 최악 `O(n)` | 빈도, 방문 여부, 빠른 포함 검사 |
| 균형 검색 트리 | 정렬 순서 유지, 연산 `O(log n)` | 해시보다 상수 비용 큼 | 범위/이웃 원소 질의 |
| 이진 힙 | 최솟값/최댓값 `O(1)`, 삽입·삭제 `O(log n)` | 임의 값 탐색 `O(n)` | 우선순위 큐, 다익스트라 |
| Trie | 문자열 길이 `L`에 대해 `O(L)` | 노드 메모리 큼 | 접두사 검색 |
| DSU | 합치기/대표 찾기 거의 `O(1)` | 경로 자체는 모름 | 연결성, Kruskal MST |

## 배열과 연결 리스트

배열은 연속 메모리에 저장되어 인덱스로 주소를 바로 계산한다. 순회가 빠르고 대부분의 문제에서 기본 선택이다. 동적 배열(C++ `vector`, C# `List<T>`, Python `list`)은 용량이 부족하면 더 큰 저장소로 이동하므로 기존 포인터·참조·반복자가 무효화될 수 있다.

연결 리스트는 각 노드가 다음 노드(이중 연결이면 이전 노드도)를 가리킨다. “삽입 위치의 노드를 이미 알고 있다”는 조건에서만 삽입이 `O(1)`이다. 그 위치를 찾는 데는 `O(n)`이 든다.

## 스택, 큐, 덱

- 스택은 LIFO(Last In, First Out, 후입선출)다. 재귀 호출도 개념적으로 호출 프레임 스택을 사용한다.
- 큐는 FIFO다. BFS의 거리 층 순서를 보장한다.
- 덱(deque)은 양 끝에서 삽입·삭제한다. 0-1 BFS와 단조 큐에 쓰인다.

Python에서 큐를 `list.pop(0)`으로 만들면 이동 비용 `O(n)`이 든다. `collections.deque`를 사용한다.

## 해시와 충돌

해시 함수는 키를 버킷 위치로 바꾼다. 다른 키가 같은 위치를 얻는 **충돌**은 정상이며 컨테이너가 처리한다. 평균 `O(1)`은 좋은 해시와 적절한 적재율을 전제로 한다. 사용자 정의 객체를 키로 쓸 때 동등성 규칙과 해시 규칙이 일치해야 한다.

## 힙과 우선순위 큐

이진 최소 힙은 부모가 자식보다 작거나 같은 완전 이진 트리다. 전체가 정렬된 것은 아니다. 최솟값 반복 추출에는 적합하지만 특정 값 검색에는 적합하지 않다.

- C++ `priority_queue`는 기본이 최대 힙이다.
- C# `PriorityQueue<TElement, TPriority>`는 낮은 우선순위를 먼저 꺼낸다.
- Python `heapq`는 최소 힙 함수 모음이다.

## 합집합-찾기(DSU)

DSU(Disjoint Set Union, 서로소 집합 합집합)는 `find(x)`로 대표를 찾고 `union(a,b)`로 두 집합을 합친다. 경로 압축과 크기/랭크 기준 합치기를 함께 쓰면 연산당 상각 `O(α(n))`이며 실질적으로 거의 상수다. 예제 세 언어 모두 구현되어 있다.

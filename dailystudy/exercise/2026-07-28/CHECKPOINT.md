# 초보자 이해 검증

아래 답을 코드 없이 말하거나 직접 수정해 재실행할 수 있으면 통과다.

## 1단계 — 문법 찾기

1. `int delivered{0};`에서 타입, 변수 이름, 초기값을 각각 말한다.
2. `publish`의 반환형과 매개변수 타입, 호출식 하나를 찾는다.
3. `struct`와 `class`의 기본 접근 차이, `public:`과 `private:`의 역할을 설명한다.
4. `ConsoleListener` 생성자에 반환형이 없는 이유, 생성자 매개변수와 멤버 초기화 목록을 가리킨다.
5. `explicit`이 막는 잘못된 암시 변환과 허용되는 직접 초기화 예를 하나씩 쓴다.
6. `ListenerPtr` 별칭과 `shared_ptr`의 템플릿 인자를 찾는다.

## 2단계 — 수명과 값 범주

1. `listener`가 lvalue인 이유를 말한다.
2. `make_shared` 결과가 prvalue인 이유와 반환 시 복사 생략 가능성을 설명한다.
3. `std::move(name)`이 xvalue를 만들지만 그 자체가 이동은 아닌 이유를 말한다.
4. `const std::string&`와 `IEventListener&&`가 각각 어떤 식에 바인딩될 수 있는지 말한다.
5. `weak.lock()` 뒤의 지역 `shared_ptr`가 가상 호출 동안 객체 수명을 어떻게 지키는지 설명한다.
6. `reset()` 뒤 객체가 파괴되고 `weak_ptr`만 남는 이유를 소유권 관점에서 설명한다.

## 3단계 — 직접 검증

1. `main.cpp`에 두 번째 구독자를 붙이고 첫 발행 결과가 `2`가 되게 수정한다.
2. 하나만 `reset()`하고 다음 발행 결과가 `1`인지 확인한다.
3. `problem.cpp`의 반복문 본문을 지운 뒤 스스로 다시 구현한다.
4. `weak_ptr` 대신 `shared_ptr`를 저장하는 버전을 잠깐 만들어 객체 수명의 차이를 설명한 뒤 원복한다.

## 4단계 — 아키텍처와 기계 관점

1. 포트(`IEventListener`), 조정자(`EventBus`), 어댑터(`ConsoleListener`)의 책임을 한 문장씩 말한다.
2. 가상 호출에서 가능한 로드·비교·조건 분기·간접 호출을 설명한다.
3. 실제 명령이 CPU, ABI, 컴파일러, 표준 라이브러리, 최적화 옵션에 따라 달라져 특정 어셈블리 명령으로 단정할 수 없다고 설명한다.

통과 기준: 1·2단계 전 항목에 답하고, 3단계 중 두 가지를 실행하며, 4단계의 책임 분리를 자신의 말로 설명한다.

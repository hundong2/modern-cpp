# 우선순위 큐와 사용자 정의 비교자

## 정의와 적용 조건

우선순위 큐는 삽입한 원소 중 “가장 높은 우선순위” 원소를 빠르게 확인·삭제하는 자료구조다. C++의 `std::priority_queue`는 보통 이진 힙으로 구현되며, 모든 원소의 완전 정렬은 필요 없고 다음에 처리할 최우선 원소만 반복해서 필요할 때 적합하다. 임의 원소 검색·삭제나 정렬 순회가 필요하면 다른 자료구조를 검토한다.

## 핵심 아이디어와 불변식

내부 컨테이너를 완전 이진 트리 모양의 배열로 보고 부모와 자식 사이의 우선순위를 유지한다. 불변식은 `top()`이 현재 모든 원소 중 비교 규칙상 가장 먼저 처리할 원소라는 것이다. C++ 비교자 `comp(a, b)`가 참이면 `a`는 `b`보다 우선순위가 낮다는 뜻이므로, 최솟값을 꺼내려면 흔히 “더 큰가”를 반환한다.

## 단계별 절차

1. 문제의 우선순위를 하나의 키로 정의한다. 여러 기준이면 `(첫 기준, 둘째 기준)`처럼 사전식 순서를 정한다.
2. `operator()`가 낮은 우선순위일 때 `true`를 반환하도록 비교자를 작성한다.
3. 삽입은 배열 끝에 원소를 추가한 뒤 부모 방향으로 올려 불변식을 복구한다.
4. 삭제는 루트와 마지막 원소를 교체해 마지막을 제거한 뒤 자식 방향으로 내려 불변식을 복구한다.
5. 비어 있는지 확인한 뒤 `top()`을 읽고 필요하면 `pop()`한다.

## 의사 코드

```text
for 명령 in 입력:
    if 삽입 명령: heap.push(값)
    else if heap이 비었음: 빈 경우 출력
    else: heap.top() 출력; heap.pop()
```

## 컴파일 가능한 C++ 뼈대

```cpp
#include <queue>   // std::priority_queue
#include <vector>  // 내부 저장 컨테이너

struct Greater {
    bool operator()(int left, int right) const {
        return left > right; // 작은 값이 top에 오도록 큰 값의 우선순위를 낮춘다.
    }
};

int main() {
    std::priority_queue<int, std::vector<int>, Greater> heap{};
    heap.push(3);
    heap.push(1);
    return heap.top() == 1 ? 0 : 1;
}
```

## 정확성 근거

삽입 전 힙 불변식이 참이라고 하자. 새 원소에서 부모 방향의 경로만 관계가 깨질 수 있으므로 그 경로에서 교환하면 모든 부모-자식 관계가 다시 만족된다. 삭제도 새 루트에서 자식 방향의 한 경로만 고치면 된다. 따라서 각 연산 뒤 `top()`은 정의한 비교 순서의 최우선 원소다. 귀납적으로 모든 명령 뒤 불변식이 유지된다.

## 시간·공간 복잡도

원소가 M개일 때 트리 높이는 O(log M)이다. `push`, `pop`은 O(log M), `top`, `empty`는 O(1)이다. M개 원소 저장 공간은 O(M)이다.

## 흔한 실수

- 비교 방향을 직관과 반대로 써서 최대 힙과 최소 힙을 뒤집는다.
- 여러 우선순위 기준 중 동률 처리 기준을 빠뜨린다.
- 빈 큐에서 `top()`이나 `pop()`을 호출해 정의되지 않은 동작을 만든다.
- 비교자가 일관된 엄격 약순서를 이루지 않게 `>=` 같은 비교를 사용한다.
- `top()`이 참조를 반환한다는 점을 잊고 `pop()` 뒤 그 참조를 사용한다.

## 변형

`std::greater<int>`로 단순 최소 힙을 만들 수 있다. 구조체 작업을 저장할 때는 마감 시각, 비용, 입력 순서 같은 복합 키를 비교할 수 있다. 모든 원소를 한꺼번에 받는다면 힙 생성은 선형 시간에 가능하며, 상위 K개만 유지하는 제한 크기 힙도 자주 사용한다.

## 오늘 문제와의 연결

BOJ 11286은 키를 `(abs(x), x)`로 정의한다. 사용자 정의 비교자는 절댓값이 큰 값을 낮은 우선순위로 두고, 절댓값이 같으면 원본 정수가 큰 값을 낮은 우선순위로 둔다. 그러면 `top()`이 요구한 출력값과 정확히 일치한다.

## 직접 해보기와 초보자 검증

1. 비교자의 `>`를 `<`로 바꾸고 출력이 어떻게 뒤집히는지 확인한다.
2. `-3, 3, -2, 2`를 차례로 넣고 내부 배열 전체가 정렬되지 않아도 `top()`이 항상 올바른 이유를 설명한다.
3. `push`와 `pop`이 왜 O(N)이 아니라 O(log N)인지 완전 이진 트리 높이로 증명한다.

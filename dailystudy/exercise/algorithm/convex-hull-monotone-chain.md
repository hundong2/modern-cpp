# 볼록 껍질과 Andrew 단조 사슬(Convex Hull, Monotone Chain)

## 정의

평면의 점 집합 `S`의 **볼록 껍질(convex hull)** 은 `S`를 모두 포함하는 가장 작은 볼록 집합이다.
점들을 고무줄로 감쌌을 때 고무줄이 닿는 경계라고 생각할 수 있다. 유한한 점 집합에서 넓이가 양수라면
경계는 볼록 다각형이 된다.

문제마다 “껍질에 포함할 점”의 정의를 먼저 확인해야 한다.

- 껍질의 방향이 바뀌는 꼭짓점만 요구할 수 있다.
- 꼭짓점뿐 아니라 껍질의 선분 위에 놓인 모든 공선점까지 요구할 수 있다.

CSES 2195는 두 번째 정의다. 따라서 세 점의 외적이 `0`일 때 가운데 점을 지우면 오답이다.

Andrew의 **단조 사슬(monotone chain)** 알고리즘은 점을 `(x,y)` 사전순으로 정렬한 뒤, 왼쪽 끝점에서
오른쪽 끝점까지 가는 lower chain과 돌아오는 upper chain을 스택처럼 만든다. 구현이 짧고 정수 좌표에서
부동소수점 없이 정확하게 판정할 수 있어 대회에서 가장 실용적인 볼록 껍질 알고리즘 중 하나다.

## 적용 조건

- 정적인 2차원 점 집합의 볼록 껍질을 한 번 구할 때 적합하다.
- 좌표가 정수라면 외적을 충분히 넓은 정수 타입으로 정확하게 계산할 수 있다.
- 입력 순서가 중요하지 않고 `O(n log n)` 정렬을 허용할 때 사용한다.
- 모든 경계점 또는 방향 전환 꼭짓점만 출력하는 두 요구를 pop 비교 하나로 구분할 수 있다.
- 점이 온라인으로 계속 추가·삭제되고 매번 껍질을 물으면 동적 볼록 껍질 자료구조가 별도로 필요하다.
- 3차원 이상의 convex hull에는 이 2차원 알고리즘을 그대로 적용할 수 없다.

## 방향 판정과 64비트 안전성

세 점 `a`, `b`, `c`에 대해 다음 외적을 사용한다.

```text
cross(a,b,c)
  = (b.x-a.x)*(c.y-a.y) - (b.y-a.y)*(c.x-a.x)
```

- `cross > 0`: `a -> b -> c`가 반시계 방향으로 돈다.
- `cross = 0`: 세 점이 한 직선 위에 있다.
- `cross < 0`: 시계 방향으로 돈다.

CSES 좌표는 각각 `[-10^9,10^9]`다. 좌표 차의 절댓값은 최대 `2*10^9`, 한 곱의 절댓값은 최대
`4*10^18`, 두 곱 차의 절댓값은 보수적으로 최대 `8*10^18`이다. 이는
`INT64_MAX = 9,223,372,036,854,775,807`보다 작으므로 모든 뺄셈과 곱셈을 처음부터 `std::int64_t`로
수행하면 공식 제약 안에서 안전하다. 좌표를 `int`에 둔 채 곱한 뒤 결과만 64비트로 변환하면 이미 32비트
곱셈에서 overflow할 수 있으므로 늦은 캐스팅은 안전하지 않다.

부호 있는 정수 overflow는 C++에서 미정의 동작이다. 좌표 범위가 더 큰 변형이라면 곱셈 전에 `__int128`
같은 더 넓은 중간 타입을 쓰거나 다중 정밀도 정수를 검토한다. `__int128`은 GCC/Clang 확장이므로 이식성이
필요하면 대상 컴파일러 계약도 확인한다.

기계 실행 관점에서 외적 하나는 좌표 로드, 정수 뺄셈·곱셈, 결과 비교와 조건 분기로 이어질 수 있다.
그러나 실제 명령 선택, 레지스터 사용, 분기 제거·벡터화 여부는 CPU, ABI, 컴파일러와 최적화 옵션에 따라
달라지므로 특정 어셈블리 형태나 비용으로 단정하지 않는다.

## 핵심 아이디어와 불변식

### 1. 사전순 정렬

점을 `(x,y)` 오름차순으로 정렬하면 사전순 최소점이 맨 왼쪽 경계의 한 끝, 사전순 최대점이 맨 오른쪽
경계의 한 끝이 된다. 같은 x에서는 y가 작은 점부터 처리하므로 세로 경계도 결정적으로 다룰 수 있다.

### 2. Lower chain

정렬한 점을 왼쪽에서 오른쪽으로 한 번 본다. 새 점 `p`를 붙였을 때 마지막 세 점이 시계 방향이면
가운데 점을 제거한다. 더 이상 시계 방향 회전이 없을 때 `p`를 넣는다.

처리한 점의 접두 구간에 대해 다음 불변식을 유지한다.

1. 스택의 점은 사전순으로 증가한다.
2. 연속한 세 점의 외적은 항상 `0` 이상이다.
3. 스택은 지금까지 본 점들의 아래쪽 볼록 경계를 이룬다.
4. 스택에서 제거된 점은 현재 아래 경계의 두 점을 잇는 선분보다 위쪽에 있어 lower chain에 필요 없다.

각 점은 한 번 들어가고 최대 한 번 빠진다. 따라서 정렬 뒤 lower 구축은 `O(n)`이다.

### 3. Upper chain

정렬 배열을 오른쪽에서 왼쪽으로 같은 규칙으로 처리한다. 연속한 세 점의 외적이 음수일 때만 가운데
점을 제거하면 오른쪽 끝에서 왼쪽 끝으로 가는 upper chain이 된다. 구현에서는 lower가 든 같은 vector의
뒤에 upper를 이어 붙일 수 있다.

### 4. 공선 경계점 보존

CSES 2195의 핵심 비교는 다음과 같다.

```text
while 마지막 세 점의 cross < 0:
    가운데 점 제거
```

`cross == 0`이면 제거하지 않는다. 정렬 순서 때문에 같은 경계 선분 위의 점들이 선분을 따라 차례로 남는다.
반대로 “방향 전환 꼭짓점만” 요구하는 문제에서는 `cross <= 0`을 사용해 가운데 공선점을 제거한다.

lower와 upper는 사전순 최소점과 최대점을 공유한다. lower의 최대점은 upper 시작점으로 재사용하고, upper가
마지막에 다시 넣은 최소점 하나를 제거하면 중복 없이 하나의 경계 순회가 된다. 입력 껍질 넓이가 양수라는
공식 조건 덕분에 lower와 upper 전체가 같은 직선이 되는 특수 경우는 없다.

## 단계별 절차

1. 모든 좌표를 signed 64-bit 정수로 읽는다.
2. 점을 `x` 오름차순, 같으면 `y` 오름차순으로 정렬한다.
3. 빈 결과 스택 `hull`을 만들고 정렬 점을 앞에서부터 처리한다.
4. `hull`의 마지막 두 점과 새 점이 시계 방향(`cross < 0`)인 동안 마지막 점을 제거한다.
5. 새 점을 `hull`에 넣는다. 이 단계가 끝나면 lower chain이 완성된다.
6. 현재 크기를 `lower_size`로 저장한다.
7. 사전순 최대점은 이미 있으므로 정렬 배열의 끝에서 두 번째 점부터 첫 점까지 역순으로 처리한다.
8. upper 부분에 마지막 점이 하나 이상 있고 마지막 세 점이 시계 방향인 동안 pop한 뒤 새 점을 넣는다.
9. 마지막에 다시 들어간 사전순 최소점을 한 번 pop한다.
10. 결과 크기와 각 좌표를 출력한다. CSES는 시작점과 시계/반시계 방향을 제한하지 않는다.

## 의사코드

```text
points를 (x,y) 오름차순 정렬
hull = 빈 스택

for p in points (왼쪽 -> 오른쪽):
    while hull.size >= 2 and cross(hull[-2], hull[-1], p) < 0:
        hull.pop_back()
    hull.push_back(p)

lower_size = hull.size

for p in points[n-2], points[n-3], ..., points[0]:
    while hull.size > lower_size and cross(hull[-2], hull[-1], p) < 0:
        hull.pop_back()
    hull.push_back(p)

hull.pop_back()  // lower 첫 점과 중복된 upper 마지막 점
return hull
```

upper의 while 조건이 단순히 `hull.size >= 2`가 아니라 `hull.size > lower_size`인 이유가 중요하다.
같은 vector 앞부분의 lower 점들을 upper 정리 과정에서 지우면 안 된다. `size > lower_size`이면 lower의
오른쪽 끝점과 upper에 막 추가한 점이 있어 외적의 두 선행점도 안전하게 읽을 수 있다.

## C++ 뼈대와 컴파일 가능한 C++20 예제

아래 예제는 공식 입력의 여섯 점을 코드에 넣고 실제로 경계점 네 개를 출력한다. 출력 순서는 공식 예시와
달라도 허용된다.

```cpp
#include <algorithm>
#include <cstddef>
#include <cstdint>
#include <iostream>
#include <vector>

struct Point {
    std::int64_t x{};
    std::int64_t y{};
};

bool less_xy(const Point& left, const Point& right) {
    if (left.x != right.x) {
        return left.x < right.x;
    }
    return left.y < right.y;
}

std::int64_t cross(const Point& a, const Point& b, const Point& c) {
    return (b.x - a.x) * (c.y - a.y)
         - (b.y - a.y) * (c.x - a.x);
}

// CSES 조건인 size>=3, 서로 다른 점, 양의 hull 넓이를 전제로 한다.
std::vector<Point> convex_hull(std::vector<Point> points) {
    std::sort(points.begin(), points.end(), less_xy);

    std::vector<Point> hull;
    hull.reserve(points.size() * std::size_t{2});
    for (std::size_t i{}; i < points.size(); ++i) {
        while (hull.size() >= std::size_t{2}
               && cross(hull[hull.size() - std::size_t{2}], hull.back(), points[i]) < 0) {
            hull.pop_back();
        }
        hull.push_back(points[i]);
    }

    const std::size_t lower_size{hull.size()};
    for (std::size_t i{points.size() - std::size_t{1}}; i-- > std::size_t{0};) {
        while (hull.size() > lower_size
               && cross(hull[hull.size() - std::size_t{2}], hull.back(), points[i]) < 0) {
            hull.pop_back();
        }
        hull.push_back(points[i]);
    }
    hull.pop_back();
    return hull;
}

int main() {
    std::vector<Point> points{
        {2, 1}, {2, 5}, {3, 3}, {4, 3}, {4, 4}, {6, 3}
    };
    const std::vector<Point> answer{convex_hull(points)};

    std::cout << answer.size() << '\n';
    for (const Point& point : answer) {
        std::cout << point.x << ' ' << point.y << '\n';
    }
}
```

이 예제가 출력하는 한 가지 유효한 순서는 다음과 같다.

```text
4
2 1
6 3
4 4
2 5
```

함수 매개변수를 값으로 받은 것은 예제의 독립성을 위한 선택이다. 호출자가 lvalue를 넘기면 점 vector를
복사하고, rvalue를 넘기면 저장소를 이동해 정렬할 수 있다. 제출 코드처럼 입력 vector를 계속 소유할 이유가
없다면 호출자에서 직접 정렬한 뒤 `const&`로 hull 구축 함수에 빌려 주어 복사 한 번을 피할 수도 있다.
반환하는 `hull`은 NRVO 대상이며, NRVO가 적용되지 않아도 vector의 이동 생성이 저장소 소유권을 전달한다.

## 정확성 근거

### 보조정리 1: lower 구축 뒤 연속 회전은 모두 반시계 또는 공선이다

새 점을 넣기 전에 마지막 세 점의 외적이 음수인 동안 가운데 점을 제거한다. pop할 때마다 다시 새 마지막
두 점과 새 점을 검사한다. 루프가 끝났다면 점이 둘 미만이거나 마지막 외적이 0 이상이다. 이전 접두 부분은
귀납 가정으로 이미 0 이상이므로 새 점을 넣은 뒤에도 lower의 모든 연속 회전은 0 이상이다.

### 보조정리 2: lower에서 pop한 점은 최종 lower 경계에 필요 없다

사전순으로 `a`, `b`, 새 점 `c`를 처리할 때 `cross(a,b,c)<0`이면 `b`는 `a`와 `c`를 잇는 lower 방향
선분보다 위쪽에 있다. `a -> b -> c`를 유지하면 아래쪽 경계가 오목하게 꺾인다. 따라서 모든 처리 점을
포함하는 볼록한 아래 경계에서 `b`는 방향 전환점이 될 수 없고 제거해도 안전하다. pop 후 더 이전 점과
`c`를 다시 검사하므로 필요한 만큼의 오목한 꼬리를 전부 제거한다.

`cross==0`인 점은 제거하지 않는다. 세 점이 같은 경계 선분에 있고 정렬 순서대로 놓였다면 가운데 점도
문제가 요구하는 경계점이므로 남기는 것이 정확하다.

### 보조정리 3: lower는 모든 아래쪽 경계점을 정확히 순서대로 포함한다

보조정리 1에 의해 결과는 볼록하고, 보조정리 2에 의해 제거된 점은 lower 경계에 필요 없다. 반대로 최종
아래쪽 지지선 위의 점은 이를 건너뛰는 시계 방향 오목 꼬리를 만들지 않으므로 제거되지 않는다. 공선인 경우도
엄격한 음수에서만 pop하므로 보존된다. 따라서 lower에는 사전순 최소점부터 최대점까지의 모든 아래 경계점이
정렬 순서로 남는다.

### 보조정리 4: upper는 모든 위쪽 경계점을 정확히 포함한다

점을 역순으로 보아 같은 논증을 적용하면 좌우가 뒤집힌 lower 문제와 같다. 따라서 사전순 최대점부터
최소점까지의 모든 위쪽 경계점이 순서대로 남으며 내부점은 제거된다.

### 정리

넓이가 양수인 볼록 다각형의 경계는 사전순 최소점과 최대점을 잇는 아래 경계와 위 경계의 합이고, 두 경계는
양 끝점만 공유한다. 보조정리 3과 4에 의해 알고리즘은 두 경계의 모든 점을 얻는다. 결합 과정에서 최대점은
한 번만 시작점으로 사용하고 마지막 최소점 중복을 pop하므로 각 입력 경계점이 정확히 한 번 남는다. 따라서
출력은 CSES 2195가 요구하는 볼록 껍질 위의 모든 점과 정확히 일치한다.

## 시간·공간 복잡도

- 사전순 정렬: `O(n log n)` 시간
- lower와 upper 구축: 각 점이 각 chain에서 한 번 push되고 최대 한 번 pop되므로 합계 `O(n)` 시간
- 결과와 정렬 입력 저장: `O(n)` 공간
- 전체: `O(n log n)` 시간, `O(n)` 공간

결과 점 수도 최악 `n`개다. 구현이 `2n` capacity를 한 번 예약하면 두 chain을 같은 vector에 이어 붙이는
동안 반복 재할당을 피할 수 있다. 알고리즘은 재귀를 쓰지 않아 입력 크기에 따른 호출 스택 overflow가 없다.

## 흔한 실수

- **`cross <= 0`에서 pop한다.** 꼭짓점만 남고 선분 위 공선점이 사라져 CSES 2195에서는 오답이다.
- **외적의 방향을 반대로 쓰면서 부호 조건을 그대로 둔다.** 함수 인자 순서와 양수 의미를 작은 삼각형으로 먼저 확인한다.
- **좌표를 64비트로 바꾸지 않고 곱한다.** `10^9 * 10^9`부터 32비트 범위를 넘는다.
- **곱한 다음에만 캐스팅한다.** overflow는 캐스팅 전에 이미 발생한다. 피연산자를 먼저 넓은 타입으로 둔다.
- **upper가 lower 원소까지 pop하게 한다.** upper 전용 꼬리가 있을 때만 pop하도록 `size > lower_size` 경계를 둔다.
- **사전순 최대점과 최소점 중복을 둘 다 출력한다.** 결합 정책을 정하고 끝점 중복을 정확히 한 번씩 제거한다.
- **unsigned 역순 루프를 `i >= 0`으로 쓴다.** `std::size_t`는 0 아래에서 큰 값으로 감겨 무한 루프/범위 밖 접근이 된다.
- **all-collinear 일반 입력을 같은 코드에 넣는다.** CSES는 양의 넓이를 보장하지만, 일반화할 때는 모든 외적이 0인지 검사해 정렬한 점을 한 번씩 반환해야 한다.
- **부동소수점 기울기로 정렬한다.** 수직선, 정밀도와 동률 문제가 생긴다. 정수 외적이 더 정확하고 단순하다.
- **입력 중복을 무시한다.** 이 문제는 서로 다름을 보장하지만 일반 함수라면 정렬 뒤 중복 제거 정책이 필요하다.

## 대회 실전 팁

1. 먼저 `(0,0),(1,0),(1,1)`의 외적이 양수인지 단위 테스트해 부호 규약을 고정한다.
2. `<= 0`과 `< 0` 중 무엇이 맞는지는 문제의 “boundary의 모든 점” 문구로 결정한다.
3. 네 모서리와 각 변 중간점, 내부점을 섞은 사각형으로 공선 보존과 내부 제거를 동시에 검사한다.
4. 같은 x 좌표가 많은 입력으로 사전순 tie-break와 세로 변 처리를 확인한다.
5. 최대 좌표 `-10^9`, `10^9`를 섞어 sanitizer와 경계 테스트를 수행한다.
6. 무작위 작은 점 집합에서는 후보 결과의 모든 연속 외적 부호와 모든 입력점이 경계 안/위인지 brute force로 검증한다.
7. 출력 순서가 자유여도 중복과 누락은 허용되지 않는다. 답 개수와 좌표 집합을 함께 검사한다.

## 변형

### 방향 전환 꼭짓점만 남기기

pop 조건을 `cross <= 0`으로 바꾸면 같은 선분 내부의 공선점이 제거된다. 단, 문제에서 공선점을 어떻게
정의하는지와 모든 점이 공선인 입력의 기대 출력을 별도로 확인한다.

### 모든 점이 공선인 일반 입력

lower와 upper가 같은 점들을 반대 순서로 담아 중복이 생길 수 있다. 입력 정렬 뒤 모든 외적이 0인지 확인해
정렬 배열 자체를 반환하거나, 결합 뒤 좌표 중복을 명시적으로 제거한다. CSES 2195는 넓이 양수 보장으로 이
분기가 필요 없다.

### Rotating calipers

꼭짓점 convex hull을 순서대로 얻은 뒤 antipodal pair를 이동시키면 가장 먼 두 점, 최소 폭, 최소 둘레
외접 사각형 같은 문제를 선형 추가 시간에 풀 수 있다. 공선점 포함 여부가 포인터 진행 조건에 영향을 준다.

### 점 포함 질의

볼록 껍질 꼭짓점이 반시계 순서라면 한 꼭짓점을 기준으로 부채꼴을 이분 탐색해 점 하나의 포함 여부를
`O(log h)`에 판정할 수 있다. 경계 포함/제외와 외적 0 처리를 질의 정의에 맞춘다.

### 동적 볼록 껍질

점 삽입이 반복되고 매번 극점/접선 질의를 해야 하면 정렬 집합에 위·아래 chain을 유지하는 방식이나 문제에
맞는 Li Chao tree/지원 함수 자료구조를 검토한다. 정적 Andrew 알고리즘을 매번 다시 돌리면 질의당
`O(n log n)`이 든다.

## 오늘 문제와의 연결

[`../2026-09-07/icpc_problem.cpp`](../2026-09-07/icpc_problem.cpp)는 CSES 2195 Convex Hull을 다음처럼
구현한다.

- 좌표와 외적을 `std::int64_t`로 두고 공식 범위에서 `8*10^18` 이내임을 증명한다.
- `point_less`로 `(x,y)` strict weak ordering을 정의해 `std::sort`한다.
- 한 `std::vector<Point>`에 lower와 upper를 이어 붙이고 `2n` capacity를 예약한다.
- 두 chain 모두 `cross < 0`일 때만 pop해 모든 경계 공선점을 보존한다.
- `lower_size`를 경계로 upper가 이미 완성된 lower 원소를 지우지 못하게 한다.
- unsigned 역순 루프를 `index-- > 0` 형태로 써 범위 밖 접근을 막는다.
- 재귀 없이 각 점을 분할 상환 상수 횟수만 처리해 200,000점 제한을 만족한다.

## 직접 해보기와 검증 질문

1. `(0,0),(1,0),(2,0),(2,2),(0,2)`를 처리할 때 lower 스택을 매 단계 적고 `(1,0)`이 남는 이유를 설명한다.
2. 같은 입력에서 pop 조건을 `<= 0`으로 바꾸면 어떤 점이 사라지는지 확인한다.
3. 좌표 차 두 개가 각각 `2*10^9`일 때 곱과 외적의 최대 절댓값을 계산해 int64_t 안전성을 증명한다.
4. upper 루프 조건을 `hull.size() >= 2`로 바꿨을 때 lower가 손상될 수 있는 실행을 추적한다.
5. `for (size_t i=n-2; i>=0; --i)`가 왜 종료하지 않을 수 있는지 unsigned 표현으로 설명한다.
6. 공식 예제에서 내부점 `(3,3)`과 `(4,3)`이 어느 chain의 어떤 외적에서 제거되는지 계산한다.
7. 모든 점이 공선인 입력을 허용하도록 함수를 일반화하고 결과에 각 점이 한 번만 나타나는지 검사한다.
8. 반환 `hull`에 NRVO가 적용될 때와 적용되지 않을 때 vector 저장소 소유권이 어떻게 전달되는지 설명한다.

# 최장 증가 부분 수열(LIS)

## 정의와 적용 조건

원소의 상대적 순서는 유지하되 일부를 생략해 값이 엄격히 증가하는 부분 수열 중 최대 길이를 구한다. 연속 구간일 필요는 없다. N이 수천 정도면 O(N²) DP가 이해와 구현에 적합하고, 더 크면 `lower_bound` 기반 O(N log N) 변형을 쓴다.

## 핵심 아이디어와 불변식

`dp[i]`를 **i번째 원소를 반드시 마지막으로 고른 LIS 길이**로 정의한다. i를 계산할 때 `j < i`인 상태는 모두 확정되어 있다. 검사한 j들 가운데 `a[j] < a[i]`인 것만 연결하며, 매 순간 `dp[i]`는 지금까지 검사한 유효한 이전 끝점으로 만들 수 있는 최장 길이라는 불변식을 유지한다.

## 단계별 절차

1. 모든 `dp[i]`를 자기 자신만 고르는 길이 1로 초기화한다.
2. i를 왼쪽부터 오른쪽으로 순회한다.
3. 각 i에 대해 모든 `j < i`를 검사한다.
4. `a[j] < a[i]`이면 `dp[i] = max(dp[i], dp[j] + 1)`로 갱신한다.
5. 모든 `dp[i]`의 최댓값을 답으로 낸다.

## 의사 코드

```text
dp[0..N-1] = 1
answer = 1
for i = 0 .. N-1:
  for j = 0 .. i-1:
    if a[j] < a[i]:
      dp[i] = max(dp[i], dp[j] + 1)
  answer = max(answer, dp[i])
```

## 컴파일 가능한 C++ 뼈대

```cpp
#include <algorithm> // std::max
#include <iostream>  // std::cin, std::cout
#include <vector>    // std::vector

int main() {
    int n{}; // 중괄호로 0 초기화한다.
    std::cin >> n;
    std::vector<int> a(static_cast<std::size_t>(n)); // 입력을 소유한다.
    for (int& x : a) { // 참조로 실제 원소에 입력한다.
        std::cin >> x;
    }
    std::vector<int> dp(static_cast<std::size_t>(n), 1);
    int answer{n == 0 ? 0 : 1};
    for (int i{0}; i < n; ++i) {
        for (int j{0}; j < i; ++j) {
            if (a[j] < a[i]) {
                dp[i] = std::max(dp[i], dp[j] + 1);
            }
        }
        answer = std::max(answer, dp[i]);
    }
    std::cout << answer << '\n';
}
```

## 정확성 근거

i에서 끝나는 증가 부분 수열의 바로 이전 원소가 j라면 반드시 `j < i`이고 `a[j] < a[i]`다. 알고리즘은 가능한 모든 j를 검사하며, 귀납 가정상 `dp[j]`는 그 j에서 끝나는 최장 길이다. 따라서 그중 최대에 1을 더한 값은 i에서 끝나는 최장 길이와 정확히 같다. 모든 LIS에는 어떤 마지막 위치 i가 있으므로 모든 `dp[i]`의 최댓값이 전체 답이다.

## 시간·공간 복잡도

모든 `(j, i)` 쌍을 최대 한 번 검사하므로 시간 O(N²), 입력과 DP 배열 때문에 공간 O(N)이다.

## 흔한 실수

- 엄격 증가인데 `<=`를 써서 같은 값을 연결한다.
- `dp`를 0으로 시작해 자기 자신 하나를 빠뜨린다.
- `dp[n-1]`만 출력한다. LIS의 마지막 위치는 어디든 될 수 있다.
- 부분 수열을 연속 부분 배열로 오해한다.

## 변형

- 비감소 부분 수열은 비교 조건을 `<=`로 바꾼다.
- 길이뿐 아니라 실제 수열이 필요하면 이전 위치 배열을 함께 저장해 역추적한다.
- O(N log N) 방식은 길이별 가능한 최소 꼬리 값을 유지한다. 길이는 맞지만 그 꼬리 배열 자체가 원래 LIS는 아닐 수 있다.

# 증강 경로 기반 이분 매칭

## 정의

이분 그래프 `G=(L,R,E)`는 정점을 왼쪽 집합 `L`과 오른쪽 집합 `R`로 나눌 수 있고 모든 간선이 서로 다른 집합의 정점만 잇는 그래프다. **매칭**은 끝점을 공유하지 않는 간선 집합이며, 그 크기가 가장 큰 것을 **최대 매칭**이라 한다. 현재 매칭에 포함되지 않은 정점을 자유 정점이라 한다.

현재 매칭 간선과 비매칭 간선을 번갈아 지나는 경로를 교대 경로라 한다. 양 끝이 자유 정점인 교대 경로는 **증강 경로**다. 경로에서 비매칭 간선을 선택하고 기존 매칭 간선을 해제하면 충돌 없이 매칭 크기가 정확히 1 증가한다.

## 적용 조건

- 직원-일, 학생-프로젝트, 사람-좌석처럼 두 종류의 대상 사이에 가능한 짝 관계가 있다.
- 양쪽 정점은 각각 최대 하나의 짝만 가질 수 있다.
- 목표가 가중치 합이 아니라 짝의 최대 개수다. 가중치가 있으면 최소 비용 최대 유량, Hungarian 등 다른 도구를 검토한다.
- 한 정점이 여러 상대와 짝지을 수 있는 용량 문제라면 정점 복제 또는 최대 유량 모델을 검토한다.

그래프가 이분인지 모르면 BFS/DFS 2색 칠하기로 먼저 검사할 수 있다. 일반 그래프 최대 매칭에는 blossom 계열이 필요하므로 이 알고리즘을 그대로 쓰면 안 된다.

## 핵심 아이디어와 불변식

오른쪽 정점 `r`마다 현재 담당 왼쪽 정점 `owner[r]` 하나만 저장한다. `-1`은 자유 상태다. 새 왼쪽 정점 `u`를 넣을 때 가능한 오른쪽 정점을 차례로 본다.

1. `r`이 비어 있으면 `u-r`을 선택해 즉시 매칭 크기를 1 늘린다.
2. `r`이 이미 `v`와 매칭되어 있으면 `v`를 다른 오른쪽 정점으로 옮길 수 있는지 재귀적으로 찾는다.
3. 이동이 성공하면 `r`의 담당자를 `u`로 바꾼다. 재귀 호출이 경로 아래쪽 담당자를 이미 옮겼으므로 전체 선택은 여전히 매칭이다.

중요한 불변식은 다음과 같다.

- `owner[r]`은 항상 하나의 왼쪽 정점 또는 `-1`이다.
- 성공한 재귀 반환마다 탐색 경로의 매칭/비매칭 간선 선택이 뒤집힌다.
- `try_match(u)`가 true를 반환하면 이전보다 매칭 크기가 정확히 1 크다.
- 한 증강 시도 안에서 오른쪽 정점은 최대 한 번 방문한다. 다시 방문해도 같은 부분 문제이므로 해를 추가로 얻지 못하고 사이클만 만들 수 있다.

## 단계별 절차

1. 입력을 왼쪽 정점별 오른쪽 인접 목록으로 저장한다.
2. 모든 오른쪽 정점의 담당자를 `-1`로 초기화한다.
3. 왼쪽 정점을 하나씩 증강 시도의 시작점으로 고른다.
4. 이번 시도의 방문 배열을 비우거나 서로 다른 정수 stamp를 사용한다.
5. 인접 오른쪽 정점마다 빈 상태인지, 현재 담당자를 다른 곳으로 옮길 수 있는지 검사한다.
6. 성공하면 담당자를 현재 왼쪽 정점으로 바꾸고 전체 매칭 크기를 1 늘린다.
7. 모든 왼쪽 정점의 시도가 끝나면 매칭 크기를 반환한다.

## 의사 코드

```text
owner[r] <- -1 for every r
answer <- 0

function augment(u, stamp):
    for each r adjacent to u:
        if seen[r] == stamp:
            continue
        seen[r] <- stamp

        if owner[r] == -1 or augment(owner[r], stamp):
            owner[r] <- u
            return true
    return false

for each u in L:
    if augment(u, unique_stamp_for_u):
        answer <- answer + 1
```

## 컴파일 가능한 C++ 뼈대

아래 예제는 `왼쪽 0={오른쪽 0,1}`, `왼쪽 1={오른쪽 0}`에서 첫 매칭을 재배정해 크기 2를 만든다.

```cpp
#include <iostream>
#include <vector>

bool augment(int left,
             const std::vector<std::vector<int>>& graph,
             std::vector<int>& owner,
             std::vector<int>& seen,
             int stamp) {
    for (const int right : graph[static_cast<std::size_t>(left)]) {
        if (seen[static_cast<std::size_t>(right)] == stamp) {
            continue;
        }
        seen[static_cast<std::size_t>(right)] = stamp;

        if (owner[static_cast<std::size_t>(right)] == -1 ||
            augment(owner[static_cast<std::size_t>(right)], graph, owner, seen, stamp)) {
            owner[static_cast<std::size_t>(right)] = left;
            return true;
        }
    }
    return false;
}

int main() {
    const std::vector<std::vector<int>> graph{{0, 1}, {0}};
    std::vector<int> owner(2, -1);
    std::vector<int> seen(2, 0);
    int answer{};

    for (int left{}; left < 2; ++left) {
        if (augment(left, graph, owner, seen, left + 1)) {
            ++answer;
        }
    }

    std::cout << answer << '\n';
    return answer == 2 ? 0 : 1;
}
```

`graph`가 간선을 소유하고 재귀 함수는 이를 `const&`로 빌린다. `owner`와 `seen`은 호출자가 소유하고 함수가 비const 참조로 갱신한다. 재귀 깊이는 최악 왼쪽 정점 수 정도이므로 제한이 매우 크면 반복 구현이나 스택 한도를 검토한다.

## 정확성 근거

### 보조정리 1: 성공한 `augment(u)` 뒤에도 선택 간선은 매칭이다

빈 오른쪽 정점 `r`을 고른 경우 `u`와 `r`은 둘 다 새 경로 끝에서 자유이므로 간선 `u-r`을 추가해도 끝점 충돌이 없다. `r`이 기존 `v`의 일이면 재귀가 먼저 `v`를 다른 오른쪽 정점으로 옮긴 뒤 `r`을 `u`에게 준다. 경로 내부에서는 기존 매칭 간선 하나를 제거할 때 새 간선 하나를 추가하므로 각 정점의 선택 차수는 계속 최대 1이다.

### 보조정리 2: 성공할 때 매칭 크기는 정확히 1 증가한다

증강 경로는 자유 왼쪽 정점에서 시작해 자유 오른쪽 정점에서 끝난다. 경로의 비매칭 간선 수는 매칭 간선 수보다 정확히 하나 많다. 두 종류를 뒤집으면 `+1`이 되며 경로 밖 선택은 변하지 않는다.

### 정리: 모든 증강 시도가 끝난 결과는 최대 매칭이다

더 큰 매칭이 존재한다면 현재 매칭과 그 매칭의 대칭차에는 현재 기준 증강 경로가 적어도 하나 존재한다(Berge의 정리). 알고리즘은 각 왼쪽 시작점에서 도달 가능한 교대 경로를 모두 검사하고, 발견할 때마다 증강한다. 종료했는데 더 큰 매칭이 있다고 가정하면 아직 찾지 않은 증강 경로가 있어야 해 탐색 종료와 모순이다. 따라서 결과는 최대다.

## 시간·공간 복잡도

- 왼쪽 정점 수를 `|L|`, 오른쪽 정점 수를 `|R|`, 간선 수를 `E`라 한다.
- 한 증강 시도에서 방문 표시 덕분에 각 오른쪽 정점과 관련 간선을 최악 한 번씩 따라가므로 `O(E)`다.
- 모든 왼쪽 정점에서 시도하므로 단순 Kuhn 구현의 최악 시간은 `O(|L| * E)`다.
- 인접 목록 `O(E)`, 담당자·방문·재귀 스택 `O(|L|+|R|)`로 전체 공간은 `O(|L|+|R|+E)`다.
- 방문 배열을 매번 `fill`하면 추가 `O(|L|*|R|)` 초기화 비용이 생긴다. stamp는 이를 상수 갱신으로 줄인다.

## 자료구조 선택

- `vector<vector<int>>`: 각 왼쪽 정점의 가능한 상대만 저장해 희소 그래프에서 행렬 `O(|L||R|)` 낭비를 피한다.
- `vector<int> owner`: 오른쪽당 담당자가 하나뿐이라는 매칭 불변식을 직접 표현한다.
- `vector<int> seen_stamp`: 매 시도마다 별도 stamp로 방문 범위를 구분하고 전체 초기화를 피한다.
- 재귀 DFS: 교대 경로 뒤집기를 간결하게 표현한다. 깊이 제한이 위험하면 부모 배열과 명시적 스택으로 바꾼다.

## 흔한 실수

1. **빈 일만 탐욕적으로 선택**: `L0={R0,R1}`, `L1={R0}` 순서에서 L0가 R0을 고르면 L1을 버리지만 재배정하면 둘 다 매칭된다.
2. **방문 배열을 전체 실행 동안 공유**: 한 증강 시도의 방문만 막아야 한다. 다음 왼쪽 정점은 같은 오른쪽 정점을 다시 탐색할 수 있어야 한다.
3. **재귀 성공 전에 owner 덮어쓰기**: 기존 담당자를 잃어 매칭 불변식이 깨진다. 먼저 기존 담당자의 이동 성공을 확인한다.
4. **1기반 입력을 그대로 인덱싱**: 문제 번호에서 1을 빼고 범위 `[0,M)`를 유지한다.
5. **양쪽 여러 배정을 허용**: 왼쪽 정점당 증강을 최대 한 번 성공시키고 오른쪽 담당자도 하나만 저장한다.
6. **일반 그래프에 적용**: 삼각형처럼 이분할할 수 없는 그래프 최대 매칭은 blossom이 필요하다.
7. **재귀 깊이 무시**: 제한이 큰 체인형 교대 경로는 호출 스택을 많이 사용한다.

## 변형과 확장

- **Hopcroft–Karp**: BFS로 자유 왼쪽 정점에서 최단 증강 경로 층을 만들고 DFS로 여러 경로를 한 단계에서 찾아 `O(E√V)`를 달성한다.
- **최대 유량**: source→왼쪽→오른쪽→sink 간선 용량을 모두 1로 두면 정수 최대 유량 값이 최대 매칭 크기다. 공용 문서 [`maximum-flow-edmonds-karp.md`](maximum-flow-edmonds-karp.md)와 연결된다.
- **최소 정점 덮개**: 이분 그래프에서는 최대 매칭 크기와 최소 정점 덮개 크기가 같다(Kőnig 정리). 실제 덮개는 최대 매칭 뒤 교대 도달성을 이용해 복원한다.
- **가중 이분 매칭**: 짝마다 가치가 있으면 단순 최대 개수와 목표가 다르므로 Hungarian 또는 최소 비용 최대 유량을 사용한다.
- **용량이 있는 정점**: 정점 복제나 유량 네트워크로 여러 배정 한도를 모델링한다.

## 오늘 문제와의 연결

[`../2026-08-27/icpc_problem.cpp`](../2026-08-27/icpc_problem.cpp)의 직원이 왼쪽 정점, 일이 오른쪽 정점이다. `jobs_by_worker`가 간선, `owner_by_job`이 현재 매칭을 나타낸다. `try_assign`은 교대 경로 DFS이며 stamp는 같은 시도의 오른쪽 일 재방문을 막는다. CTest의 재배정 사례는 단순 탐욕이 실패하고 증강 경로가 필요한 최소 증거다.

## 직접 검증

1. `L0={R0,R1}`, `L1={R0}`을 두 순서로 처리하며 owner 배열 변화를 적는다.
2. 재귀 호출 전에 `owner[r]=u`를 대입한 잘못된 구현의 반례를 만든다.
3. 방문 stamp를 제거했을 때 교대 사이클에서 호출이 반복되는 과정을 그린다.
4. 최대 매칭 결과에서 교대 도달성을 이용해 최소 정점 덮개를 복원해 본다.
5. 정점 6개 이상의 입력을 만들고 Kuhn과 최대 유량 모델의 답이 같은지 비교한다.
6. 간선이 밀집한 `N=M=1000`에서 `O(N*E)` 연산량을 추정하고 Hopcroft–Karp 필요성을 판단한다.

# 표준 라이브러리를 읽기 위한 공통 용어

## 선언과 항목의 종류

- **헤더(header)**: `#include <vector>`처럼 선언을 현재 번역 단위에 보이게 하는 표준 라이브러리 단위다. 헤더를 포함한다고 컨테이너 객체가 자동 생성되는 것은 아니다.
- **타입(type)**: 저장 형태와 가능한 연산의 집합이다. `std::vector<int>`는 `int`를 원소 타입으로 갖는 구체 타입이다.
- **클래스 템플릿(class template)**: 타입이나 값을 인자로 받아 구체 타입을 만드는 틀이다. `std::vector<T>`의 `T`가 템플릿 인자다.
- **함수(function)**: 매개변수를 받고 결과를 반환하거나 부수 효과를 수행한다. `std::move`처럼 실제로는 함수 템플릿인 항목도 있다.
- **멤버 함수(member function)**: `values.size()`처럼 특정 객체와 함께 호출한다. 점 왼쪽 객체는 암시적 객체 인자이며 `const` 멤버 함수는 그 객체를 통해 관찰 가능한 상태를 바꾸지 않는다.
- **함수 객체(function object)**: `operator()`를 가진 객체다. `std::greater<int>`와 람다는 호출 문법을 사용하지만 상태를 가질 수 있다.
- **표준 객체**: `std::cout`, `std::cin`, `std::nullopt`처럼 함수가 아닌 이름 있는 객체 또는 태그다.

## 컨테이너와 메모리

- **컨테이너(container)**: 여러 값을 소유하고 저장·탐색·삽입 API를 제공하는 타입이다.
- **연속 컨테이너(contiguous container)**: 원소가 연속 메모리에 놓여 포인터 산술과 캐시 지역성의 이점을 갖는다. `vector`, `array`, `string`이 대표적이다.
- **어댑터(container adapter)**: 내부 컨테이너의 API를 제한하거나 다른 추상화를 제공한다. `queue`, `priority_queue`는 반복자를 직접 노출하지 않는다.
- **크기(size)**: 현재 들어 있는 원소 수다. **용량(capacity)**은 재할당 없이 저장 가능한 원소 수다.
- **재할당(reallocation)**: 더 큰 저장소를 만들고 기존 원소를 이동·복사한 뒤 옛 저장소를 해제하는 과정이다. 보통 기존 포인터·참조·반복자를 무효화한다.
- **할당자(allocator)**: 컨테이너가 원시 메모리를 얻고 객체를 구성·파괴하는 정책을 추상화한다. `std::pmr`은 실행 시간에 메모리 자원을 주입한다.

## 반복자와 범위

- **반복자(iterator)**: 컨테이너 위치를 가리키며 `*it`, `++it`, 비교 같은 연산을 제공하는 일반화된 포인터다.
- **끝 반복자(end iterator)**: 마지막 원소가 아니라 마지막 다음 위치를 나타낸다. 역참조하면 안 된다.
- **범위(range)**: 시작과 끝으로 순회 가능한 원소 집합이다. C++20 ranges는 반복자 쌍뿐 아니라 범위 객체 자체를 받는다.
- **센티널(sentinel)**: 순회의 끝을 판정하는 값이다. 시작 반복자와 같은 타입일 필요가 없어 일부 지연 범위를 효율적으로 표현한다.
- **뷰(view)**: 원소를 소유하지 않거나 최소 상태만 소유하면서 다른 범위를 지연 변환·필터링한다. 원본보다 오래 보관하면 댕글링이 될 수 있다.
- **프로젝션(projection)**: 비교 전에 각 원소에서 비교할 값을 꺼내는 함수다. ranges 알고리즘이 구조체 필드를 기준으로 정렬할 때 유용하다.
- **술어(predicate)**: 원소를 받아 참/거짓을 반환하는 호출 가능 객체다. 순수 함수일 필요는 없지만 알고리즘 요구사항을 깨는 부수 효과는 피한다.
- **비교자(comparator)**: 두 값을 받아 엄격 약순서를 정의한다. `a<b`와 `b<a`가 모두 거짓이면 정렬 관점에서 동등하다.

## 소유권과 수명

- **소유자(owner)**: 객체 파괴 책임을 가진 값이다. 컨테이너와 스마트 포인터가 대표적이다.
- **관찰자(observer)**: 객체를 사용하지만 파괴 책임은 없다. 참조, 포인터, `span`, `string_view`, `weak_ptr`가 상황에 따라 관찰자다.
- **댕글링(dangling)**: 가리키던 객체 수명이 끝나 더는 유효하지 않은 포인터·참조·반복자·뷰 상태다. 사용하면 미정의 동작이 될 수 있다.
- **RAII**: 자원 획득을 객체 초기화에 묶고 소멸자가 자원을 반납하게 하는 기법이다. 잠금, 파일, 메모리, 스레드 합류에 적용된다.
- **값 의미론(value semantics)**: 값을 복사하면 독립된 논리 값을 얻고 이동하면 원본 자원을 재사용 가능한 유효 상태로 넘기는 모델이다.
- **어휘 타입(vocabulary type)**: 계층 경계를 넘어 의미를 전달하는 표준 타입이다. `optional`, `expected`, `variant`, `span` 등이 “없음”, “실패”, “여러 선택”, “비소유 범위”를 타입에 기록한다.

## 호출과 오류 계약

- **전제조건(precondition)**: 호출자가 호출 전에 만족해야 하는 조건이다. 위반 시 예외가 아니라 미정의 동작인 API도 있다.
- **사후조건(postcondition)**: 정상 반환 뒤 라이브러리가 보장하는 상태다.
- **복잡도 보장**: 구현의 평균 측정값이 아니라 표준이 요구하는 연산 횟수 상한이다. `vector::push_back`은 상각 `O(1)`이다.
- **강한 예외 보장**: 예외가 나면 호출 전 상태가 유지된다.
- **기본 예외 보장**: 예외가 나도 객체 불변식과 자원 안전성은 유지되지만 값은 바뀔 수 있다.
- **`noexcept`**: 함수가 예외를 밖으로 내보내지 않겠다는 계약이다. 위반해 예외가 빠져나오면 `std::terminate`가 호출된다.
- **오류 코드**: `std::error_code`처럼 예외 대신 값으로 실패를 전달한다. 호출자는 반환 상태와 오류 값을 모두 확인해야 한다.
- **빈 상태**: `optional`, `expected`, `weak_ptr::lock` 결과처럼 정상적인 부재를 타입 상태로 표현한다.

## 컴파일 시간과 실행 시간

- **`constexpr`**: 조건을 만족하면 컴파일 시간 평가가 가능하고 실행 시간 호출도 허용하는 함수·객체다.
- **concept**: 템플릿 인자가 제공해야 하는 연산과 의미를 이름 붙인 컴파일 시간 제약이다.
- **타입 특성(type trait)**: `std::is_same_v`, `std::remove_cvref_t`처럼 타입 정보를 계산하거나 변환하는 템플릿이다.
- **타입 소거(type erasure)**: 구체 타입을 숨기고 공통 호출 계약으로 저장하는 기법이다. `std::function`이 대표적이며 간접 호출과 저장 비용이 생길 수 있다.
- **코루틴 프레임**: 일시 중단 지점 사이에 지역 상태를 보존하는 컴파일러 생성 객체다. `coroutine_handle`은 프레임을 가리키지만 기본적으로 소유권을 자동 관리하지 않는다.

## 동시성

- **데이터 경쟁(data race)**: 동기화 없이 같은 메모리에 동시에 접근하고 그중 하나 이상이 쓰기인 상황이다. C++에서는 미정의 동작이다.
- **원자성(atomicity)**: 다른 스레드가 연산의 중간 상태를 관찰하지 못한다는 성질이다. 다른 메모리의 순서까지 자동 보장하는 것은 아니다.
- **메모리 순서(memory order)**: 원자 연산이 주변 메모리 접근의 관찰 순서를 얼마나 제약하는지 정한다.
- **happens-before**: 한 작업의 효과가 다른 작업에서 관찰되도록 언어가 보장하는 순서 관계다.
- **협력적 취소**: 작업을 강제로 중단하지 않고 토큰을 확인한 작업 코드가 안전한 지점에서 스스로 종료하는 방식이다.

## 미정의·미지정·구현 정의

- **미정의 동작(UB)**: 표준이 결과를 제한하지 않는다. 범위를 벗어난 `vector::operator[]`, 댕글링 참조 역참조, 데이터 경쟁이 예다.
- **미지정 동작**: 허용된 여러 결과 중 구현이 하나를 선택하지만 문서화 의무는 없다.
- **구현 정의 동작**: 구현이 선택하고 문서화해야 한다. 기본 타입 크기의 일부 성질이 여기에 속한다.

## 기계 실행 관점 주의

소스의 함수 호출이 실제 기계 코드의 호출 명령 하나와 일대일 대응한다고 가정하면 안 된다. 인라이닝, 상수 전파, 복사 생략, 벡터화, 잠금 구현, ABI 호출 규약 때문에 로드·저장·비교·분기·간접 호출이 합쳐지거나 사라질 수 있다. 구체 결과는 대상 CPU, ABI, 표준 라이브러리, 컴파일러와 최적화 옵션을 고정한 뒤 생성 코드를 확인해야 한다.

## 사용하는 방법

1. 날짜 행에서 코드 파일과 심볼을 확인한다.
2. 코드의 인접 주석에서 현재 호출의 인자·반환·상태 변화를 읽는다.
3. 공용 심볼 색인에서 복잡도·수명·무효화·오류 계약을 확인한다.
4. 새 코드가 생기면 감사 스크립트를 실행하고 누락된 대표 문서를 중복 없이 보강한다.
